投后理财账户服务报告｜业务评审说明

评审版本：业务评审版 v1.0
评审目标：确认周期/主动查询、客户画像、三类报告、对应话术、标准方案素材和受控企微群发闭环。

一、评审范围

本包为独立的投后理财账户服务场景，与理财投后异动服务报告并列。页面不互相跳转，业务链路可在 GWork 中串联。

本次评审重点覆盖：

  1. 周期任务、批量自由圈客和单客安全任务码查询；
  2. 客户列表、风险等级、整体持仓和理财持仓；
  3. 周报、月报、诊断与优化报告及各自对应话术；
  4. 报告长图预览/下载、话术页内编辑和合规失败兜底；
  5. 页面顶部小C/大C五档标准方案公共素材及完整长图预览；客户详情沟通话术下方的客户五档方案素材、单选和群发加入反馈。

二、建议评审路径

原型评审画布：先打开 原型评审画布，查看顶部 AC-01 至 AC-14 逻辑主链，再按九个 frame 平铺状态核对页面与浮层；右侧“需求文档”可切换交互逻辑映射。画布用于状态总览和研发逻辑评审；需要逐步点击时请进入下方“可点击原型”。

  1. 打开可点击原型，确认顶部展示生成来源和生成时间，且没有独立任务批次卡。
  2. 搜索并切换客户，检查风险等级的业务展示口径和账户概览。
  3. 切换周报、月报、诊断与优化报告，确认每份报告有自己的更新时间、摘要、长图预览、下载和对应话术。
  4. 点击话术正文直接编辑，失焦后确认保存；检查人工编辑后不显示“合规通过”标签。
  5. 在顶部公共方案区域核对小C、大C两份素材展示的五档名称和比例，并分别点击“预览长图”查看完整附件；确认顶部公共素材不进入群发。
  6. 切换客户，在沟通话术下方打开“客户五档方案素材”，确认仅展示该客户持仓对应的小C/大C类型；分别在抽屉中选择档位，验证同一类型单选、默认不选、切换档位自动替换、切换客户状态不串，并测试预览/下载。
  7. 点击“加入群发素材”，确认外层卡片展示已加入的类型和档位；再打开左侧企微群发，检查客户级方案素材与报告长图、对应话术一起展示，异常/不可触达内容排除且底部确认按钮固定。

三、已确认业务规则

  • 未指定报告类型时默认生成周报、月报、诊断与优化报告三类；指定时只生成指定类型。
  • 有最新报告优先复用，无可用报告时在 GWork 内现场调用对应报告 Skill。
  • 三类报告独立处理，单类异常不阻塞其他成功报告及话术。
  • 每份报告生成一份对应话术，话术只使用对应报告作为输入。
  • 话术合规失败最多重生成三次；三次失败后该话术人工编辑前不可复制和触达，人工编辑后无需再次审核。
  • 顶部小C、大C是服务清单页面级公共素材，固定展示在顶部任务概览下方，不随当前客户变化；仅支持预览，不进入群发。
  • 顶部两份素材均展示低波动15%、中低波动30%、中波动50%、中高波动65%、高波动80%，点击后分别预览 PNG / PDF 完整长图。
  • 客户详情的“客户五档方案素材”位于沟通话术下方，仅按客户持仓展示可用类型；小C、大C分别最多单选1档，默认不选，选择按客户独立保存。每档可预览/下载，加入后在外层显示并作为当前客户群发附加素材。
  • 报告预览为只读长图，不提供发送操作；群发从左侧客户列表发起，按客户和报告类型计算可发送内容。

四、交付边界

本包包含服务清单的可点击原型和单客任务码中转页面 PRD。任务码中转页是已确认的安全查询需求，当前没有对应 HTML 原型；研发应依据 Spec 和页面 PRD 实现。

五、评审通过标准

  • 业务能区分三类报告与三份对应话术。
  • 业务能理解报告异常、合规失败和人工编辑后的触达权限。
  • 业务能在页面顶部直接查看小C、大C五档方案比例并打开对应完整长图。
  • 业务能在群发确认中识别可发送内容、排除原因和防重规则。
  • 研发可根据正式 Spec、主 PRD、页面 PRD 和原型开始技术方案拆解。
