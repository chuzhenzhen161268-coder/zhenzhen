1. 页面定位

1.1 核心目标

让客户经理或投顾从一份服务清单中查看客户已完成的周报、月报、诊断与优化报告及各自对应的话术，并基于可发送内容完成企微触达。

1.2 入口与出口

  • 入口：员工消息中的动态任务名称、周期任务结果、批量自由圈客结果，或通过单客安全任务码中转获取的查询结果。
  • 出口：报告长图预览/下载、话术复制、左侧客户列表中的企微一键群发；不与异动服务报告页面互跳。

2. 页面结构

模块 内容与职责
顶部摘要 标题、副标题、生成来源、生成时间；右侧展示服务客户数、报告任务数、已完成数
左侧客户清单 客户搜索、企微一键群发入口、客户行
右侧客户详情 客户画像、标准方案素材、周报/月报/诊断 Tab、报告摘要、话术
报告预览浮层 对应报告长图只读预览

群发确认浮层 按客户、报告和话术状态拆分的可发送内容与收件人确认

3. 元素与展示规则

3.1 顶部摘要

  • 生成来源展示为“员工消息「{动态消息名称}」”或实际来源类型；生成时间为本次服务清单生成时间，格式 YYYY-MM-DD HH:mm。
  • 不再展示“当前任务批次”独立卡片，也不在页面上展示“群发成功回执用于防重”的内部机制说明。
  • 右侧仅展示服务客户、报告任务、已完成等汇总指标。原型中的名称、时间、数量均为演示数据。

3.2 左侧客户清单

  • 支持按客户姓名或资金账号实时搜索。
  • 客户行展示姓名、资金账号、风险等级与整体持仓；按整体持仓金额降序。
  • 风险等级展示业务口径，例如“C3（中风险承受）”“C4（中高风险承受）”；专业投资者展示“专业投资者（无需测评）”。
  • 企微一键群发入口固定在搜索框下方、客户行上方，使用蓝色描边整行按钮。
  • 成功触达的报告不允许再次进入群发；该规则在群发确认内容中体现，不额外占用页面说明区。

3.3 客户详情与三类报告

  • 顶部显示姓名、资金账号、风险等级、持有产品类别；统计客户整体持仓、理财持仓、最近服务时间。
  • 使用 Tab 分别查看理财账户周报、理财账户月报、诊断与优化报告。每个 Tab 独立显示报告更新日期、摘要、查看完整报告、下载图片及其对应沟通话术。
  • 完整报告以长图呈现。点击“查看完整报告”仅打开只读预览，预览不提供发送给客户或企微发送操作。
  • 报告生成异常时，在对应 Tab 显示异常状态及重新生成入口；其他成功报告不受影响。
  • 当前服务清单不展示“受到异动影响的持仓金额和占比”。

3.4 沟通话术与合规

  • 周报、月报、诊断与优化报告分别生成一份对应话术；不得将不同报告的内容混写为一份话术。
  • 正常 AI 话术可直接点击正文进入页内编辑框；失焦后保存非空内容，空内容不保存。复制入口置于话术卡标题右侧。
  • 三次合规审核失败的客户/报告，展示“AI生成话术未通过合规审核，请自行编辑话术”及待人工编辑状态；未编辑前禁止复制和任何企微触达。
  • 人工编辑直接在当前话术模块内完成，不使用弹窗；保存后恢复复制和企微触达能力，无需再次合规审核；人工编辑话术不展示“合规通过”标签。
  • 原型可用单独的演示客户呈现合规失败状态，不在正常客户上覆盖模拟失败。

3.5 标准方案素材

  • 标准方案素材是当前客户维度的公共模块，位于客户概况之后、报告 Tab 之前，随右侧详情区域滚动；不放入诊断与优化报告正文。
  • 持有公募产品展示“小 C 标准方案”，持有私募产品展示“大 C 标准方案”，同时持有两类则同时展示；不按客户资产金额或画像继续筛选档位。
  • 外层仅展示小 C/大 C 方案卡与“查看 5 档方案”，不罗列五档名称、不在外层展示预览/下载按钮。
  • 侧拉抽屉展示五档：低波动方案、中低波动方案、中波动方案、中高波动方案、高波动方案。每一档均为独立长图素材，支持预览、下载和勾选。
  • 默认不勾选。点击“加入群发素材”仅将勾选档位加入当前客户的群发素材，不直接发起企微发送；外层卡片显示已加入的档位及数量。
  • 五档方案的勾选状态按客户隔离保存，不得因切换客户而共享或覆盖其他客户选择。
  • 方案预览浮层必须覆盖抽屉层级，关闭预览后仍可继续操作抽屉。

3.6 企微一键群发

  • 群发确认按“客户 → 可发送报告及对应话术 → 当前客户已选标准方案素材”分层展示，确认按钮固定在弹窗底部。
  • 每位客户分别计算可发送内容：仅发送报告成功且对应话术可触达的报告长图及话术；异常报告、待人工编辑话术、已成功触达的报告不发送，并注明原因。
  • 标准方案素材按客户各自选择附加，不得把当前客户勾选的方案发送给其他客户。
  • 收件人可取消勾选；没有任何可发送报告/话术时禁用确认发送。
  • 发送成功后记录“客户 + 报告类型”回执并用于防重；同一客户其他尚未触达的报告可继续发送。

4. 交互定义

触发元素 操作 系统响应
搜索框 输入 实时过滤客户清单；无结果时提示未找到匹配客户
客户行 点击 更新右侧客户详情；默认切换至周报 Tab；恢复该客户独立的方案选择和话术状态
报告 Tab 点击 切换当前报告、摘要、更新时间、话术及异常状态
查看完整报告 点击 打开只读长图预览，只能关闭
下载图片 点击 下载/演示下载对应报告或方案长图
报告异常重试 点击 触发重新生成；成功后重新进入相应报告与话术流程
话术正文 点击，编辑后失焦 进入页内编辑；失焦保存非空内容；人工编辑后恢复该话术可复制/触达状态
复制话术 点击 仅在当前话术可触达时复制并提示成功
标准方案卡 点击“查看 5 档方案” 打开对应小 C/大 C 右侧抽屉
方案勾选 勾选/取消 更新当前客户、当前方案类型的独立选择状态
加入群发素材 点击 将已勾选档位加入当前客户群发素材，关闭抽屉并更新外层选中状态
左侧企微一键群发 点击 打开按客户/报告/话术/素材拆分的确认浮层
群发确认收件人 勾选/取消 实时更新待发送客户数和可发送报告/话术数
确认发送 点击 发送当前可用内容、写入回执并反馈发送数量；按钮固定在弹窗底部

5. 页面状态

状态 表现/规则
默认态 首位客户、周报 Tab；展示来源/生成时间、客户概况及适用标准方案卡
搜索空态 左侧显示无匹配客户，右侧不展示旧客户详情
报告成功态 显示报告摘要、更新时间、只读长图预览、下载及对应话术
报告异常态 对应 Tab 标记异常，提供重新生成；其他 Tab 正常可用
话术正常态 可点击编辑并可复制；群发可纳入该报告和对应话术
合规失败待编辑态 仅该报告话术待人工编辑；禁止复制/群发/单聊，其他报告不受影响
人工编辑态 编辑内容失焦保存；移除合规通过标签，恢复该话术复制与触达能力
方案抽屉态 默认五档均未勾选；方案预览覆盖抽屉层级
群发确认态 仅纳入可发送的逐客户逐报告内容及各自素材；确认按钮固定底部
已触达态 同一客户同一报告类型不再加入群发，其他可用报告仍可发送

6. 业务约束

  • 报告在 GWork 内优先复用，缺失时现场调用开发三部 Skill；报告和对应话术完成后才进入服务清单，不展示中间生成过程。
  • 员工未指定报告类型时，默认处理周报、月报、诊断与优化报告三类；指定时只处理指定类型。
  • 单客主动查询通过安全任务码中转，批量查询使用自由圈客；中转页不是本页面的导航组件。
  • 标准方案素材不参与报告或话术生成，不因客户画像改写。
  • 原型为静态交互 Demo，不代表真实 Skill、长图文件、企微发送、回执和防重服务已经实现。
