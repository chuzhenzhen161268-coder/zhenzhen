# 投后理财账户服务报告｜业务评审检查清单

## 一、入口与客户清单

- [ ] 周期任务、批量自由圈客、单客任务码均可进入同一服务清单流程。
- [ ] 单客查询不直接把客户敏感信息传给 WorkBuddy。
- [ ] 顶部展示动态生成来源和生成时间，不展示独立任务批次卡。
- [ ] 左侧搜索框支持客户姓名和资金账号。
- [ ] 风险等级按 C1-C5 及承受能力说明展示；专业投资者显示无需测评。
- [ ] 企微群发入口位于左侧客户列表搜索框下方。

## 二、三类报告与话术

- [ ] 周报、月报、诊断与优化报告分别展示。
- [ ] 每份报告展示自己的更新时间、摘要、完整报告查看和下载。
- [ ] 完整报告为长图，预览层仅预览，不提供发送操作。
- [ ] 每份报告对应一份话术，不混用其他报告内容。
- [ ] AI 话术可直接点击编辑，失焦保存。
- [ ] 合规失败三次后人工编辑前不可复制/群发；人工编辑后恢复，且不展示“合规通过”。
- [ ] 单类报告异常不影响其他报告和话术。

## 三、标准方案素材

- [ ] 顶部公共素材固定展示在任务概览卡片下方，不随当前客户变化，且不进入群发。
- [ ] 小C、大C两张卡均展示低波动15%、中低波动30%、中波动50%、中高波动65%、高波动80%。
- [ ] 点击小C“预览长图”可查看 PNG 完整方案。
- [ ] 点击大C“预览长图”可查看 PDF 完整方案。
- [ ] 客户详情的“客户五档方案素材”位于沟通话术下方。
- [ ] 客户详情按公募/私募持仓展示可用小C/大C类型；无对应持仓时不展示该类型。
- [ ] 小C、大C在侧拉抽屉内分别使用单选，默认不选；选择新档位自动替换旧档位，客户之间选择状态不串。
- [ ] 每档支持预览和下载；加入后外层显示已加入的类型与档位。

## 四、企微群发与结论

- [ ] 群发确认按客户、报告、对应话术和客户级方案素材分层展示，不包含顶部公共方案素材。
- [ ] 客户级方案素材只随已选择该方案的对应客户发送，不在客户之间共享。
- [ ] 异常报告、待人工编辑话术、已触达报告不发送并显示原因。
- [ ] 确认发送按钮固定在弹窗底部。
- [ ] 成功回执按客户+报告类型防重，其他未触达报告仍可发送。
