# 投后理财账户服务报告｜业务评审说明

> 评审版本：业务评审版 v1.0  
> 评审目标：确认周期/主动查询、客户画像、三类报告、对应话术、标准方案素材和受控企微群发闭环。

## 一、评审范围

本包为独立的投后理财账户服务场景，与理财投后异动服务报告并列。页面不互相跳转，业务链路可在 GWork 中串联。

本次评审重点覆盖：

1. 周期任务、批量自由圈客和单客安全任务码查询；
2. 客户列表、风险等级、整体持仓和理财持仓；
3. 周报、月报、诊断与优化报告及各自对应话术；
4. 报告长图预览/下载、话术页内编辑和合规失败兜底；
5. 按客户隔离的小 C/大 C 五档标准方案素材和企微群发。

## 二、建议评审路径

1. 打开可点击原型，确认顶部展示生成来源和生成时间，且没有独立任务批次卡。
2. 搜索并切换客户，检查风险等级的业务展示口径和账户概览。
3. 切换周报、月报、诊断与优化报告，确认每份报告有自己的更新时间、摘要、长图预览、下载和对应话术。
4. 点击话术正文直接编辑，失焦后确认保存；检查人工编辑后不显示“合规通过”标签。
5. 在标准方案公共区域打开小 C/大 C 抽屉，检查五档预览、下载、默认不勾选和按客户隔离选择。
6. 点击加入群发素材，再打开左侧企微群发，检查逐客户逐报告的可发送内容、异常排除和底部固定确认按钮。

## 三、已确认业务规则

- 未指定报告类型时默认生成周报、月报、诊断与优化报告三类；指定时只生成指定类型。
- 有最新报告优先复用，无可用报告时在 GWork 内现场调用对应报告 Skill。
- 三类报告独立处理，单类异常不阻塞其他成功报告及话术。
- 每份报告生成一份对应话术，话术只使用对应报告作为输入。
- 话术合规失败最多重生成三次；三次失败后该话术人工编辑前不可复制和触达，人工编辑后无需再次审核。
- 标准方案是客户公共素材，不属于诊断报告正文；公募展示小 C，私募展示大 C，同时持有两类则两组均展示。
- 五档名称为低波动、中低波动、中波动、中高波动、高波动；默认不勾选，选择状态按客户隔离。
- 报告预览为只读长图，不提供发送操作；群发从左侧客户列表发起，按客户和报告类型计算可发送内容。

## 四、交付边界

本包包含服务清单的可点击原型和单客任务码中转页面 PRD。任务码中转页是已确认的安全查询需求，当前没有对应 HTML 原型；研发应依据 Spec 和页面 PRD 实现。

## 五、评审通过标准

- 业务能区分三类报告与三份对应话术。
- 业务能理解报告异常、合规失败和人工编辑后的触达权限。
- 业务能按客户分别选择标准方案素材，不会跨客户串用。
- 业务能在群发确认中识别可发送内容、排除原因和防重规则。
- 研发可根据正式 Spec、主 PRD、页面 PRD 和原型开始技术方案拆解。
