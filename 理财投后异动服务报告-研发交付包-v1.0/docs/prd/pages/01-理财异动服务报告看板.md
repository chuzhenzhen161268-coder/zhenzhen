## 1. 页面定位

### 1.1 核心目标
将系统主动监测或员工在 GWork 查询形成的异动结果，转化为可筛选、可解释、可执行的客户与产品服务清单。

### 1.2 入口与出口
- 入口：员工消息中的动态任务名称，或 GWork 主动查询生成的服务清单。清单页面本身独立打开。
- 出口：报告预览/下载、复制话术、客户维度企微一键群发、产品维度按产品一键群发；不跳转到账户服务报告页面。

## 2. 页面结构

| 模块 | 内容与职责 |
|---|---|
| 顶部任务摘要 | 标题、副标题、生成来源、生成时间；右侧展示组合异动、大类资产异动、影响客户、影响产品数量 |
| 异动范围 | 全部/组合层面/大类资产层面筛选；横向单行事件卡列表 |
| 维度工具栏 | 客户/产品维度切换及当前范围说明 |
| 左侧清单 | 受影响客户或受影响产品；搜索；客户维度额外提供企微一键群发入口 |
| 右侧详情 | 选中客户/产品的画像、匹配事件、报告、话术与操作 |
| 浮层 | 异动报告长图预览、企微群发确认 |

## 3. 元素与展示规则

### 3.1 顶部摘要
- 生成来源从任务元数据动态展示，格式为“员工消息「{动态消息名称}」”；如来源为系统主动任务，应按实际来源类型展示，不固定伪装成员工消息。
- 生成时间按本次清单生成时间展示，格式 `YYYY-MM-DD HH:mm`。
- 右侧展示组合异动数、大类资产异动数、影响客户数、影响产品数。
- 不展示有效期、重复触发防重机制等后台规则文案。
- 原型内任务名、时间和统计数字均为演示数据，不代表固定生产值。

### 3.2 异动范围与事件卡
- 范围筛选：全部异动、组合层面异动、大类资产层面异动。
- 默认选中“全部异动”，且默认不选中任何单张事件卡；全部异动表示汇总范围，不等于选择第一张事件。
- 事件卡展示事件名称/标的、层级、实际触发指标及观测值、触发规则、影响客户数和影响产品数。观测字段按事件类型区分，例如组合当日收益率、连续交易日累计收益/跌幅、资产单日跌幅、连续 N 日累计跌幅或近 20 日最大回撤；不得用不匹配事件的通用“异动值”替代。
- 事件卡保持单行横向滚动，不换行；超出可视区域时显示左右滚动控制，滚动只改变视口，不改变筛选状态。
- 点击事件卡后，卡片高亮，并联动筛选左侧对象清单和右侧详情中的命中事件。
- 返回全部异动：点击“全部异动”范围筛选；同时清除单事件选择并恢复汇总清单。
- 切换组合/资产范围或客户/产品维度时清除此前单事件选择，避免旧筛选残留。

### 3.3 维度工具栏与左侧清单
- 客户维度支持按客户姓名或资金账号搜索；客户按受影响持仓金额降序，金额相同按受影响占比降序。
- 客户字段：姓名、资金账号、风险等级、受影响持仓金额、受影响占比。风险等级按业务标签展示，如“C3（中风险承受）”“C4（中高风险承受）”“专业投资者（无需测评）”。
- 产品维度支持按产品名称搜索；产品按受影响比例降序。
- 客户维度的企微一键群发入口位于左侧客户清单标题下、搜索框之后/客户列表之前；切换至产品维度后隐藏。
- 当前筛选范围无匹配对象时，左侧显示无匹配提示，右侧显示无详情提示。

### 3.4 客户详情
- 客户概况：姓名、资金账号、风险等级、客户整体持仓、客户理财持仓、受影响持仓金额及占比。
- “受影响产品与命中异动”采用一个表格，每个产品一行，字段为产品名称、持仓金额、持仓收益率、命中异动。
- 一个产品命中多个异动时，在同一行的命中异动单元格内逐项展示事件名称、异动层级、实际观测指标/值和命中条件；不重复产品持仓信息。
- 对单事件/异动层级筛选，仅保留符合当前范围的客户产品与命中事件。
- 异动服务报告按 Report Skill 实际返回的报告文件逐份展示；前端不得按客户、产品或异动规则自行合并、拆分或补造报告。多份文件以固定宽度卡片单行横向排列，超出区域横向滚动；单份文件沿用同一结构，不展示报告一句话总结。
- 每张报告卡展示报告名称、关联异动名称、异动层级和可用状态；可用文件分别提供“预览”和“下载”。预览打开对应报告的长图只读浮层，仅提供关闭操作，不出现发送给客户或企微发送操作。
- 沟通话术按客户综合其相关异动及受影响产品生成一份千人千面内容。话术可点击进入页内编辑框，失焦保存；空内容不保存并提示。支持复制；客户维度不提供单独企微发送按钮。

### 3.5 产品详情
- 产品概况展示产品名称、类型、受影响比例和与当前产品相关的异动。
- 命中异动列表按事件逐项展示层级、真实指标和值、触发规则及产品匹配依据；多事件不压缩成一个混合数值。
- 产品异动服务报告与客户维度使用同一多文件规则：按 Report Skill 实际返回文件逐份横向展示，每份独立只读预览和下载；预览不提供发送操作，也不展示报告一句话总结。
- 产品话术为该产品的通用内容，可点击编辑并失焦保存、可复制。
- 持有客户列表展示客户姓名、持仓资产、持有收益和查看操作。
- “按产品一键群发”向该产品持有客户发送同一产品报告长图与产品沟通话术；可在确认弹窗取消个别收件人。

## 4. 交互定义

| 触发元素 | 操作 | 系统响应 |
|---|---|---|
| 异动层级筛选 | 点击 | 更新事件卡、对象清单和详情；清除单事件选择 |
| 事件卡 | 点击 | 单选该事件并联动对象清单、详情命中事件 |
| 全部异动 | 点击 | 清除单事件选择，恢复全部事件汇总结果 |
| 事件卡左右控制 | 点击 | 横向滚动卡片，不改变筛选条件 |
| 客户/产品维度 | 点击 | 切换搜索规则、排序、清单与详情结构；清除单事件选择 |
| 搜索框 | 输入 | 实时过滤当前筛选范围对象；无结果时展示空状态 |
| 清单对象 | 点击 | 更新选中态和右侧详情 |
| 报告卡横向列表 | 滚动 | 浏览当前对象全部报告文件；不改变异动筛选、客户/产品选择或报告顺序 |
| 报告卡预览 | 点击 | 打开当前报告文件对应的长图只读预览；关闭后返回原页面上下文 |
| 报告卡下载 | 点击 | 下载/演示下载当前报告文件；不影响其他报告卡或群发内容 |
| 话术正文 | 点击、编辑后失焦 | 进入行内编辑；失焦保存非空内容，空内容不保存 |
| 复制话术 | 点击 | 复制当前编辑后内容并显示反馈 |
| 客户维度企微一键群发 | 点击 | 打开群发确认；当前筛选内客户默认选中，可取消个别客户；发送内容为客户专属报告长图和对应千人千面话术 |
| 产品维度按产品一键群发 | 点击 | 打开群发确认；该产品持有客户默认选中，可取消个别客户；发送内容为同一产品报告长图和通用话术 |
| 确认发送 | 点击 | 关闭弹窗并反馈发送客户数；真实发送与回执由正式系统实现 |

## 5. 状态

| 状态 | 表现/规则 |
|---|---|
| 默认态 | 全部异动、客户维度；不选中单张事件卡；展示汇总对象清单与首个可用客户详情 |
| 层级筛选态 | 事件卡和对象清单仅限组合或大类资产范围 |
| 单事件态 | 仅显示该事件相关对象，详情只显示当前范围内的命中关系；可点全部异动返回 |
| 产品维度态 | 展示产品清单、产品异动详情、持有客户及按产品群发入口 |
| 搜索空态 | 提示当前范围没有匹配客户/产品，右侧不保留过期详情 |
| 多报告态 | 当前对象有多份可用报告文件时，固定宽度报告卡单行横向滚动；每份独立预览和下载 |
| 报告预览态 | 当前报告文件的只读长图预览，无任何发送操作 |
| 群发确认态 | 展示收件人及发送内容；产品异常或未通过合规审核的话术不得发送；成功回执用于防重 |
| 报告异常/空态 | 无可用报告文件时展示空/异常状态；部分文件异常时保留其余可用文件，异常卡禁用预览/下载；不伪造报告内容，重试按上游能力处理 |
| 话术合规失败态 | 三次自动重生成仍失败时展示指定提示；人工编辑前禁止复制及任何企微触达，编辑后无需重新审核即可恢复 |

## 6. 业务约束

- 组合与大类资产异动阈值、组合优先级、5 个交易日防重、资产穿透占比和产品资格规则以关联 Spec 为准。
- 报告优先复用已生成内容；没有可用报告时在 GWork 调用报告 Skill。报告成功后才生成话术；话术及合规完成后进入清单。服务清单只消费 Report Skill 返回的报告文件清单及关联异动元数据，不在页面端推导拆分粒度。
- 客户维度综合同一客户多个异动和产品；产品维度每个产品单独形成通用报告/话术。
- 员工人工编辑话术不标记为“合规通过”；人工编辑后按已确认规则恢复触达能力。
- 原型为静态交互 Demo，不代表真实企微发送、报告文件服务、回执、防重或客户数据接口已经实现。
