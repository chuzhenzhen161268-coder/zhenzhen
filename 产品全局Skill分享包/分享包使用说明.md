# 产品全局 Skill 分享包

本包用于分享给其他产品经理，包含产品 Skill 使用地图、完整 Skill 包，以及可单独安装的 `prototype-restore`。

## 推荐使用顺序

1. 双击打开 `产品Skill使用说明.html`，先查看“什么时候用哪个 Skill”。
2. 一次安装全部能力：解压 `产品全局Skill包.zip`，将其中的 11 个 Skill 文件夹复制到个人 Codex Skills 目录。
3. 只需要上线后逆向还原产品时：解压 `prototype-restore.zip`，单独复制该 Skill 文件夹。
4. 新开对话，优先输入：`使用 pm-workflow，帮我判断这个需求该从哪里开始。`

## 重要说明

- `prototype-restore` 需要已有前端源码或可运行构建产物，适合研发上线后逆向还原产品文档和高保真可交互原型。
- 其他阶段按使用地图选择对应 Skill，不要求每个项目都完整走完全部阶段。
- 产品使用地图中的完整包链接和独立包链接均为当前文件夹内的相对路径，整个文件夹可直接复制或压缩分享。

## 包含文件

- `产品Skill使用说明.html`：可视化使用地图。
- `产品全局Skill包.zip`：11 个全局 Skill 的完整安装包。
- `prototype-restore.zip`：产品原型逆向还原 Skill 独立安装包。
