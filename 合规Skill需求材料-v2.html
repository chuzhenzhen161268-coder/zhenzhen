安全围栏分析

结论：线上自定义词库没有证券合规词，且存在明显误拦风险（词库导出 2025-06-16 ~ 2026-06-16，共 190 条，涉政词为主）。

  1. 无证券业务词："保本""稳赚""必涨"等均未建；
  2. 词库有大量宽泛词——"腐败"（近 7 天命中 7 次）、"洗脑"（5 次）、"军事冲突""南海""澳门""领导人"——这些都是财经资讯的正常用语，事中同步拦截可能会造成误拦。（目前这些词汇等级是"嫌疑"，未到"不通过"级别）
优化方案

由合规 Skill 检测证券业务不合规关键词（保本 / 稳赚不赔 / 包赚 / 零风险 / 暴利 / 首选 / 行业第一等）

评测样本集方案

用途：上线验收的依据，上线后每次规则、提示词、底层模型变更的回归测试基线。

构成（按审核项组织，对齐厂商清单"正面 / 反面 / 边界示例"结构）

样本类型作用每审核项数量（建议）
违规样本测漏报：明显违规 + 变体违规（同义改写、谐音、隐喻、拆字）≥4（红线项加倍）
合规样本测误报：正常业务话术，重点收录"贴边"样本（含敏感词但合规使用，如"投资有风险，入市需谨慎"）≥4
边界样本统一口径：判定依赖场景 / 口径的灰例，由合规给出标准答案≥2

规模：按清单 12 项 × 10 ≈ 120 条。

来源

① 历史事后质检命中案例（脱敏）；② 合规典型案例与监管处罚案例改写；③ LLM 辅助生成变体与困难样本（标签须经合规审定）；④ 试运行期业务 Skill 真实生成内容抽样。

标注规范

每条样本 = 文本 + 场景（话术 / 行动建议）+ 期望结论（合规 / 不合规）+ 期望不合规项 + 判定依据（对应清单条目）。标签由合规（Owner）审定及复核。

评测指标

  • 漏报率（违规样本被判合规）：红线项建议零容忍，整体门槛会上确定；
  • 误报率（合规样本被判不合规）：过高会导致大量无效重新生成、内容产出率下降，门槛会上确定；
  • 不合规项定位准确率：不仅判对"不合规"，还要判对是哪一项、原因是否正确——这是驱动自动重新生成的关键。
防过拟合机制

样本集分两半——开发集（技术调试提示词用）与盲测集（合规保管，仅验收时使用，不参与调试）；验收后冻结为基线 V1.0，新发现的漏报案例持续补入。
