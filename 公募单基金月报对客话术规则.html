一、设计原则

  1. 员工定位是”翻译者”，不是”评价者”
    话术核心是帮客户快速定位月报重点，不替客户判断这只基金好不好。

  2. 只说”基金”，不说”客户账户”
    月报是千人一面、单只基金层面的报告，话术保持这一边界，不引用客户个人收益、持仓金额或账户盈亏。

  3. 持有建议如实传达，员工不加个人判断
    月报中的”持有建议”（含继续持有、替换、调整等结论）是经内容审核后的统一口径，可如实进入对客话术。员工照传即可，不叠加个人投资观点，也不改写建议方向。除持有建议外，话术其余部分仍只客观呈现业绩、持仓方向、管理人观点。

  4. 以”阶段收益 + 管理人观点”为锚
    客户最关心两个问题：基金最近表现如何？管理人怎么看后市运作？话术围绕这两点展开。

  5. 篇幅与组合月报对齐
    单基金月报话术字数按月报档位控制：120–180 字（含结尾服务语）。

二、变量说明

概念约定（重要）：本表所有「变量」本质上是话术最终输出给客户的那段文字（即一份话术中可被替换的片段），不是数据库字段。表中各列含义如下：

  • 变量：话术中可被替换的占位符，也是客户最终看到的那段文字。
  • 含义：该输出片段要表达的内容。
  • 示例：客户最终看到的样子。
  • 输入来源：该变量从哪儿获取——系统类变量指数据系统/业务系统，AI 提炼类变量指月报原文中的哪个章节/字段。
  • 生成方式：从输入到输出的处理方式，分三类（系统自动填入 / 系统自动计算 / AI 提炼）。

三、月报话术模板

适用内容框架

  • 基金定位（名称、代码、风险等级）
  • 业绩表现（本月、今年以来，含基金 vs 业绩比较基准 vs 同类指数三层对比）
  • 持仓方向（重仓行业/赛道 + 贡献方向，一句话，不点个股）
  • 管理人观点（提炼为 1–2 句）
  • 后续运作建议（如实传达月报中经审核的持有建议）

话术模板

这是您持有的{基金名称}（代码：{基金代码}）的{报告周期名称}运作月报，核心内容为您梳理如下：

  1. 业绩表现：{报告周期词}收益{月收益率}，今年以来的话{年初至今收益率}；与业绩比较基准相比，{基金对基准对比}；与同类指数相比，{基金对同类对比}。
  2. 持仓方向：{报告周期词}基金{持仓方向}。
  3. 管理人观点：{管理人观点}。
  4. 后续建议：{持有建议标签}：{持有建议摘要}。

报告已发您，有空看看，有疑问随时找我。

说明：第 4 条「后续建议」如实传达月报中经内容审核的持有建议结论（{持有建议标签} + {持有建议摘要}）。持有建议段中的「详细分析段」（含具体业绩数据、负面评价性语言、替代产品名等）不进入对客话术。若某只基金月报无持有建议字段，前端省略该条。同理，第 3 条「管理人观点」若月报中无该字段，前端也省略该条。模板根据实际可用字段动态退回 2–4 条结构。

模板说明：

  • “持仓方向”段承担了持仓特征 + 业绩归因的功能——单基金月报通常无独立业绩归因表，重仓行业与收益贡献方向由 AI 在一句话内合并呈现。
  • 业绩对比分”业绩比较基准”和”同类指数”两层，比组合报告多一维，对应月报原文中”业绩比较基准”和”偏股混合型基金指数”两行。

四、话术规则：重点展示与规避项

4.1 必须展示的数据/信息

内容 说明
报告类型与周期 让客户明确这是”月报”
基金名称与代码 明确是哪只基金的报告
阶段收益 报告期内的基金收益率，建议同时附”今年以来”维度
业绩基准对比 与业绩比较基准对比，按 4.4 分级表述
同类指数对比 与同类指数对比，按 4.4 分级表述
管理人观点 必须提炼为 1–2 句，不能直接贴原文
持仓方向 重仓行业/赛道 + 收益贡献方向，一句话呈现，不点个股
持有建议 如实传达月报中经内容审核的持有建议结论

4.2 单基金特有展示项

  • 业绩对比分两层：基金 vs 业绩比较基准（合同约定的对标）、基金 vs 同类指数（客户感知对标）。两层都要呈现，但表达轻重可不同——一般”基金 vs 同类指数”对客户更直观。
  • 持仓方向只到行业级：可点名行业/赛道（如”通信、电力设备”），绝不点名个股名称（如”中际旭创””宁德时代”等）。
  • 不展开前十大明细：前十大持仓表不进话术，避免给客户”押宝”错觉。

4.3 不允许出现的内容

禁止项 原因
客户个人账户收益/持仓金额 月报是基金层面，非客户个人业绩
基金具体净值点位 无客户理解价值，且易引起过度关注
单只个股名称（来自前十大持仓） 个股层面属高敏感信息，点名易引发客户追涨杀跌
持有建议”详细分析段”（含具体业绩数据、负面评价、替代产品名等） 详细分析段不进对客话术，由员工在线下与客户单独沟通；话术只取”持有建议标签”+”持有建议摘要”两段
“业绩很差/跑输太多”等负面绝对化表述 应保持专业中立，可表述为”阶段性承压”
员工个人投资观点或推荐 员工是服务者，不应输出个人投资判断
对未来收益的承诺 如”接下来会涨””保证回本”等
未经提炼的市场分析长文 月报原文较长，直接转发会增加客户阅读负担

4.4 业绩对比的表述规则（不对称处理：赢了报数字、输了模糊化）

业绩对比分两层（基准、同类），两层均按以下分级处理：

  • 有正向超额：可突出，例如”跑赢基准 X%”或”跑赢同类指数 X%”。
  • 无明显超额：表述为”与基准表现相近””与同类指数接近”，不报具体数字。
  • 小幅落后：表述为”阶段性小幅落后基准/同类指数”，不强调具体差距。
  • 落后较多：不主动强调超额，重点放在”持仓方向”和”管理人观点”上。

4.5 特殊场景：大幅回撤 / 极端行情

基金出现明显回撤或市场剧烈波动时（参考阈值：单月回撤超过 -5%，可按基金波动特征调整），话术处理优先级如下：

  1. 业绩对比走 4.4”落后较多”档：如实说明但不强调差距，避免”跌得多/亏损大”等绝对化表述，可用”阶段性承压”。
  2. 重心从”业绩对比”转向”持仓方向”和”管理人观点”，让客户看到管理人在积极应对。
  3. 管理人观点按第六节规则提炼，但不承诺反弹、不预测点位（呼应 4.3 禁止项）。
  4. 结尾可适当加一句安抚性但不承诺的服务用语，如”如有疑问我随时为您解读”。

五、AI 提炼通用规则

话术模板中所有”AI 提炼”类变量（{基金对基准对比} / {基金对同类对比} / {持仓方向} / {管理人观点}）都遵循同一套通用约束。具体每个变量的输入字段、提炼目标、兜底表述见第六节。

5.1 为什么必须提炼

月报原文通常信息密度高、专业术语多、段落较长，直接转发给客户会：

  • 增加客户阅读负担，降低报告触达效率；
  • 容易出现敏感表述（如具体宏观数据、单只个股、未承诺的观点）；
  • 不同员工表述差异大，影响品牌一致性。

此外，业绩对比类变量（{基金对基准对比} / {基金对同类对比}）虽然输入为结构化数值，但最终输出是自然语言表述——需要 AI 根据 4.4 分级框架和当期市场语境生成贴合话术基调的句子，不适合用固定模板机械拼接。

{持有建议标签} 与 {持有建议摘要} 不属于 AI 提炼类变量，按月报原文结论直接填入，不在本节约束范围内。

因此所有 AI 提炼类变量禁止直接转发原文，必须按统一规则压缩、转换、抽象。

5.2 通用提炼禁区（所有变量都适用）

  • 不保留原文宏观数据罗列：如”CPI 同比 X%、PMI X%”、具体涨跌幅排名等。
  • 不保留原文中的单只个股名称：即使月报原文前十大持仓有点名，话术也只到行业/赛道级。
  • 不保留原文中过于详细的行业涨跌描述：如”通信板块上涨 12.3%、电力设备下跌 5.6%”。
  • 不保留原文未承诺 / 不确定的观点：如”可能””或将””存在不确定性”等措辞。
  • 不输出员工个人投资判断：员工是服务者，不是投资决策者。
  • 不承诺未来收益：如”会涨回来””保证回本”等绝对化表述。
  • 不出现负面绝对化词汇：”业绩很差””跑输太多””跌得厉害”等，应改为”阶段性承压”等中性表述。

注意：本节禁区仅约束 AI 提炼类变量（4 个），不约束系统自动填入的持有建议相关变量。持有建议变量的填入规则见 5.4。

5.3 通用兜底原则

如果原文观点分散、字段缺失、AI 提炼置信度低，统一按以下优先级处理：

  1. 优先使用各变量自带的兜底表述（见第六节）；
  2. 如无兜底表述，则输出空字符串，由前端按规则决定是否省略对应模板片段；
  3. 兜底表述需由内容运营团队审核后才可上线，避免不同批次报告兜底口径不一致。

5.4 持有建议变量的填入规则（非 AI 提炼）

{持有建议标签} 与 {持有建议摘要} 为结构化字段，是月报中经内容审核的统一口径，系统直接取值、原样传达，不走 AI 提炼、不做改写：

变量 取值位置 处理方式
{持有建议标签} 【】内的枚举标签 系统自动填入，不改写、不过滤
{持有建议摘要} 标签后同行的摘要句 系统自动填入，不改写、不过滤（已在月报源头审核）
{持有建议详细} 标签/摘要下方的详细分析段 不进入对客话术，由员工线下与客户单独沟通

若月报中无”持有建议”字段，三个变量均输出空，前端省略话术第 4 条。

六、各变量 AI 提炼规则

6.1 {基金对基准对比}

项 内容
输入字段 净值系统的 {月收益率} {年初至今收益率} {业绩基准月收益} {业绩基准年初至今收益} + 月报原文市场分析字段（用于表述风格对齐）
提炼目标 一句话自然语言表述基金 vs 业绩比较基准的相对表现
提炼公式 先按 4.4 业绩对比分级（跑赢 / 相近 / 小幅落后 / 落后较多）确定档位 → 结合当期市场背景生成贴合话术基调的表述
输出约束 单一短句；跑赢场景可带具体超额百分数（”跑赢基准 X%”），其余档位不报具体差额数字；不出现”业绩很差””跑输太多”等负面绝对化词汇；不评价市场、不预测后市
示例（跑赢） “跑赢基准 12.36 个百分点”
示例（相近） “与业绩比较基准表现相近”
示例（小幅落后） “阶段性小幅落后基准”
示例（落后较多） 不直接报对比，转由 4.4 兜底到”持仓方向”和”管理人观点”段，变量留空或省略模板片段
兜底表述 “与业绩比较基准表现相近”

6.2 {基金对同类对比}

项 内容
输入字段 净值系统的 {月收益率} {年初至今收益率} + 指数系统的 {同类指数月收益} {同类指数年初至今收益}（如偏股混合型基金指数）+ 月报原文市场分析字段（用于表述风格对齐）
提炼目标 一句话自然语言表述基金 vs 同类指数的相对表现
提炼公式 先按 4.4 业绩对比分级（跑赢 / 相近 / 小幅落后 / 落后较多）确定档位 → 结合当期市场背景生成贴合话术基调的表述
输出约束 单一短句；跑赢场景可带具体超额百分数（”跑赢同类指数 X%”），其余档位不报具体差额数字；不出现”业绩很差””跑输太多”等负面绝对化词汇；不评价市场、不预测后市
示例（跑赢） “跑赢同类指数 10.99 个百分点”
示例（相近） “与同类指数表现接近”
示例（小幅落后） “阶段性小幅落后同类指数”
示例（落后较多） 不直接报对比，转由 4.4 兜底到”持仓方向”和”管理人观点”段，变量留空或省略模板片段
兜底表述 “与同类指数表现接近”

6.3 {持仓方向}

项 内容
输入字段 月报原文”前十大持仓”章节 + “持有建议”段中关于业绩分析的事实性描述（收益、回撤、贡献方向等）
提炼目标 一句话说明本期重仓行业/赛道，以及对收益贡献较大的方向
提炼公式 从前十大持仓按行业汇总后取权重最高的 1–2 类 → 结合持有建议段的业绩分析提取贡献为正的方向 → 合并为一句话
输出约束 单一句子；先说重仓行业（”以XX、XX为主”），再点贡献方向（”XX方向对本期收益贡献较大”）；如重仓行业与贡献方向一致可简写；不点个股名；不出现具体百分比；不输出持有建议段中的内部评价性语言
示例 “以通信、电力设备为主，通信和新能源方向对本期收益贡献较大”
示例（量化类） “持仓较为分散，以工业、TMT、周期为主，体现量化多策略的分散优势”
示例（承压） “以XX、XX行业为主，XX方向阶段性承压”
兜底表述 “本期基金持仓较为分散，未呈现明显单一行业集中”

6.4 {管理人观点}

项 内容
输入字段 月报原文”管理人观点 / 市场展望”字段
提炼目标 合并压缩为 1–2 句话，前半句说报告期市场环境，后半句说管理人对后市运作方向的判断
提炼公式 {管理人观点} = 市场状态 + 关键驱动 + 运作方向 + 应对思路
输出约束 总字数控制在 60–100 字；用分号或句号串联两个半句；不出现具体宏观数据；不出现内部评价性语言；不承诺反弹 / 不预测点位
示例（正面） “报告期内市场风格切换较为频繁，本基金通过量化模型约束共同风险，在较大波动中保持了超额收益的相对稳定”
示例（承压） “报告期内市场震荡加剧，本基金阶段性承压；管理人认为短期波动仍可能持续，将保持原有策略方向、等待市场企稳”
字段缺失处理 若月报中无”管理人观点 / 市场展望”字段，不使用兜底表述，输出空字符串，由前端省略话术第 3 条整条（不显示”管理人观点：”标题）
兜底表述 仅在字段存在但提炼置信度低时使用：”报告期内市场整体以震荡为主；管理人认为当前市场仍以震荡为主，本基金维持原有策略方向不变”

6.5 AI 提炼失败的统一处理

如某变量（含 {基金对基准对比} {基金对同类对比} {持仓方向} {管理人观点} 四个 AI 提炼变量）连续 N 次触发兜底（建议 N=3 次），由内容运营团队介入核查：

  • 月报原文字段是否缺失；
  • 净值/指数系统数据是否异常（针对业绩对比类变量）；
  • 提炼 prompt 是否需要根据新月报形态迭代；
  • 是否需要新增预设行业词库或兜底表述。

对照说明：

  • 持有建议拆分传达：标签”替换为更优标的” + 摘要”业绩波动较大，建议调整”（对应设计原则第 3 条）
  • 详细分析段不进话术：原文中”近三年业绩和最大回撤均弱于业绩比较基准””长期持有体验欠佳””客户很难拿住”等不出现（对应 4.3 禁止项）
  • 替代产品名不进话术：原文中点名的”华安事件驱动量化”不出现（对应 4.3 禁止项）

八、使用建议

  1. 全篇仅提供一套月报话术模板，通过变量区分不同基金，无需员工判断报告类型。
  2. 建议在产品系统中配置变量自动填充，员工只需确认即可发送，减少个人发挥空间。
  3. 对于”持仓方向”和”管理人观点”提炼，建议由内容运营团队统一输出标准摘要，避免不同员工表述差异过大。
  4. 业绩对比优先呈现”基金 vs 同类指数”（客户感知对标），”基金 vs 业绩比较基准”作为合同对标参考放在前面。
  5. 持有建议段中点名的具体替代产品/推荐产品不进入话术——方向性建议可传达，但其中点名的产品名由员工在线下与客户单独沟通。
  6. 定期回顾客诉和反馈，重点观察客户是否因”业绩对比口径”或”持有建议传达”产生误解，持续优化规则。
