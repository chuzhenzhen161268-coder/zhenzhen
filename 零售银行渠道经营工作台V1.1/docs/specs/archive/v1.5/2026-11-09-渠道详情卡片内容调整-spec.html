一、需求背景

目标用户：员工端＝零售客户经理（查看本人名下网点排名）；团队长端＝团队长（查看团队网点排名）。与现有用户一致，不新增画像。

要解决的问题：员工端「名下渠道排名」与团队长端「团队总览 · 按网点」都是排名页，行内已展示当前排名指标的数值；但两页渠道行展开的「渠道详情卡片」内又铺满经营指标 4 项 + 过程指标 4 项，与行内信息重复、信息过载。此次把卡片收敛为「渠道名称 + 渠道建档信息」，让卡片承担「这个渠道是谁、建档底细如何」的就地查看职责，不再重复承载经营/过程指标。

竞品差异 / 品类惯例：不适用（本次为既有页面内卡片内容替换，未做外部调研）。内部惯例对齐：建档信息（建码日期 · 已建码天数、关键人列表、星级 + 星级变化）沿用员工端「我的渠道」选中网点后的网点建档卡片表述。

AI 能力边界：不适用（纯信息展示，无 AI 参与）。

二、逻辑补齐摘要

2.1 主成功路径

  • 员工端：「我的渠道」（全部网点态）→ 点经营结果指标卡 → 进入「名下渠道排名」→ 点某网点行 → 行下方展开渠道详情卡片（完整渠道名称 + 渠道建档信息）→ 再次点击该行收起。
  • 团队长端：「团队总览」→ 切换到「按网点」维度 → 点某网点行 → 行下方展开渠道详情卡片（完整渠道名称 + 渠道建档信息）→ 再次点击该行收起。

2.2 关键分支

  • 展开 / 收起：整行点击 → 该行下方原地展开 / 收起；同一列表同时仅展开一行（点击另一行时原展开行收起）——沿用现状，本次不改。
  • 卡片内容：完整渠道名称（不省略）+ 渠道建档信息三项：①建码日期 · 已建码天数；②关键人列表（职位 + 姓名 + 生日，全部展示、不设条数上限）；③网点星级 + 星级变化——网点星级仅用星形图标展示（5 星制：实星表示达级、空星表示未达级），不再附「一星／二星／三星」等文字档位；右侧仍为相对上期的星级变化。
  • 关键人区排布（本次新增规范）：关键人标签默认「每行两个」（各占半宽）；当单个标签的「职位 + 姓名 + 生日」在半宽内放不下时，标签内文字自然换行，完整展示、不截断、不溢出；标签较多时逐行自然折行，不设条数上限。
  • 周期口径：卡片内星级变化随页面当前「时间周期」刷新（页面本就带周期属性）；建码日期 / 天数与关键人为静态档案，不随周期变化。
  • 指标移除：卡片内不再展示经营指标 4 项（新增资产 / 新增有效户 / 新增开户数 / 经营积分）与过程指标 4 项（拜访次数 / 活动次数 / 需求总数 / 需求未满足）。
  • 只读：两端卡片均只读，不提供「编辑建码信息」入口。
  • 维度区分（团队总览）：「按网点」维度整行点击 = 展开 / 收起卡片；「按员工」维度无卡片，点击行进员工详情（现状不变）。

2.3 状态与异常

  • 状态：收起（默认）/ 展开（同一列表同时仅一行）。
  • 空态：某渠道无建档数据（无建码日期、无关键人）→ 展开后仍展示完整渠道名称，并以轻量占位「暂无建档信息」兜底。
  • 缺项：建码日期缺失时该行文字以「—」占位；关键人列表为空时不渲染关键人区（由整体空态兜底）。
  • 回退：团队总览展开态下切换排名维度 → 卡片收起（「按员工」维度无卡片）。

2.4 跨页影响

  • 受影响页（2 处）：员工端「名下渠道排名」；团队长端「团队总览」· 按网点维度（含首页 Top4 预览区与「查看完整排名」完整页）。
  • 被动影响：卡片内容由 8 项指标降为建档信息，展开行高整体变小；行点击行为（展开 / 收起）不变。
  • 不涉及：员工端 / 团队长端「渠道星级详情页」的渠道行展开卡片（保持原「完整名称 + 经营 4 项 + 过程 4 项」口径，不改）。

2.5 仍未决项

  • 无阻塞项。

五、验收标准

  1. 主路径可完成：员工端「名下渠道排名」与团队长端「团队总览 · 按网点」点网点行 → 行下方展开卡片 → 展示完整渠道名称 + 建档信息（建码日期·天数、关键人列表、星级 + 星级变化）→ 再次点击收起。
  2. 指标移除：两处卡片内不再出现经营指标 4 项与过程指标 4 项。
  3. 只读口径：两处卡片均无「编辑建码信息」入口。
  4. 周期口径：切换页面「时间周期」，卡片内星级变化同步刷新；建码日期 / 天数与关键人列表保持不变。
  5. 空态口径：无建档数据的渠道展开后展示「暂无建档信息」占位，且仍展示完整渠道名称。
  6. 范围守界：第四节列出的项均未变化（尤其两端「渠道星级详情页」卡片保持原样）。
  7. 关键人区排布：两端卡片的关键人标签默认每行两个；单个标签的「职位 + 姓名 + 生日」在半宽内放不下时标签内自然换行，展示完整、无截断与溢出。

六、风险与依赖

  • 前置依赖（阻塞）：需网点级建档数据（建码日期、关键人列表、星级及星级变化）。当前网点主数据仅有 名称 / 银行品牌 / 距离，无建码日期、无关键人；建档数据现仅存在于员工端「我的渠道」上下文。兜底：数据未到位时原型按演示数据派生，卡片降级为「完整渠道名称 + 暂无建档信息」；研发阶段需补网点级建档字段与聚合接口。
  • 推翻既有决策（局部覆盖）：本 Spec 将「名下渠道排名」「团队总览 · 按网点」两处卡片口径，由《2026-11-03-渠道详情卡片-spec.md》的「完整名称 + 经营 4 项 + 过程 4 项」改为「完整渠道名称 + 渠道建档信息」，属对该 Spec 在这两处的局部覆盖；「渠道星级详情页」两处仍沿用原口径。已于 2026-11-09 在其顶部追加「修订记录」并对其 §2.2 / §五第 4 条逐条标注废除范围，两 Spec 互相引用。需同步更新两份 PRD 对应章节与 manifest 决策记录。
  • 卡片长度变化：卡片内容由 8 项指标降为建档信息，展开行高整体变小；关键人较多时卡片可能变长（已定全部展示、不设条数上限），随列表滚动自然展开，不影响列表排序与滚动位置；关键人标签默认每行两个、长标签自动换行，进一步压缩行高。
