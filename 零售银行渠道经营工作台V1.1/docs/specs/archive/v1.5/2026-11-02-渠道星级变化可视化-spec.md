# 渠道星级变化可视化 — 需求规格（Spec）

**产品名称**：零售银行渠道经营工作台
**模式**：迭代 (iterate)
**平台类型**：移动端 Web（企微 H5）
**日期**：2026-11-02
**迭代版本号**：零售员工工作台 `v1.5` / 零售团队长看板 `v0.4`
**流程设计要求**：单版（仅新增「点星级条目 → 进入渠道星级详情页」的穿透与返回，属小改，无需多版对比）

---

## 一、需求背景

**目标用户**：与现有用户一致。员工端＝客户经理（名下管辖一批网点）；团队长端＝团队长（管辖团队覆盖的全部网点）。

**要解决的问题**：当前两端的星级只展示"当期结果值"，看不到星级相对上期的升降。员工无法及时发现重点渠道的星级波动，团队长也无法识别团队内正在掉星的渠道。改造后：列表层可按周期查看各星级数量变化；点击星级条目进入渠道星级详情页查看该星级下的网点排列，每个网点行右端展示该周期相对上期的星级变化（升星/降星/持平），并可按变化类型只看升星 / 降星 / 无变化；员工端在「我的渠道」选中网点后，网点信息卡片也能直接看到该网点的星级变化。

**竞品差异 / 品类惯例**：不适用。本产品为内部经营工作台，无对外竞品；"趋势箭头 + 颜色"为成熟通用范式，本次沿用产品既有趋势色（↑红 / ↓绿 / —灰），不另造一套。

**AI 能力边界**：不适用（本需求不涉及 AI 生成 / 判断 / 自动化）。

> 备注：真实用户反馈中的"小程序端"指员工日常使用的移动端入口；本产品端形态为企微 H5，本次不改变端形态。

## 二、逻辑补齐摘要

### 2.1 主成功路径

用户在列表层（团队长端「星级渠道」可切换周期）看到各星级数量 → 点击某星级条目 → 进入「星级渠道详情页」→ 查看该星级、该周期下的网点列表，每个网点行右端展示相对上期的星级变化 → 可通过顶部「周期」下拉切换周期，或通过「星级变化」下拉筛选升星 / 降星 / 无变化，星级快照、网点列表与变化图标同步刷新。

并行主路径（员工端）：「我的渠道」选中某网点 → 网点信息卡片中该网点星级图标右侧展示该周期相对上期的星级变化，周期跟随「我的渠道」顶部周期下拉切换刷新。

### 2.2 关键分支

- **列表层周期切换（团队长端「星级渠道」）**：切换 昨日 / 本周 / 自然月 / 本年 → 各星级渠道数量与占比按所选周期重算
- **员工端「我的渠道」/ 团队长端「员工详情」的星级分布**：不重复加周期控件，直接跟随页面顶部既有「时间周期」下拉刷新
- **详情页周期切换**：选择 昨日 / 本周 / 自然月 / 本年 → 星级快照整体重算（星级归属、各星级数量、网点列表、变化图标均按所选周期重算）
- **详情页星级变化筛选（两端详情页）**：选择 全部 / 升星 / 降星 / 无变化 → 网点列表按变化类型过滤；星级 pills 上的数量同步显示过滤后的条数；过滤后无匹配时展示空态
- **变化判定**：升星 → ↑红；降星 → ↓绿；无变化 → 灰「—」；新网点 / 上期无评级 → 不显示图标（图标不可点）
- **三处入口统一进各自端的详情页（员工端「渠道星级详情页」/ 团队长端「星级渠道详情页」）**：员工端「我的渠道」进入时预置所点星级、星级变化取默认「全部」（周期不重置，进入时继承「我的渠道」当前周期；进入后页内可独立切换、不回写「我的渠道」）；团队长端「星级渠道」进入时预置所点星级；团队长端「员工详情」进入时预置该员工筛选
- **员工端「渠道星级详情页」不提供网点筛选**：详情页展示该星级下的全部渠道，不再受「我的渠道」所选网点影响
- **员工端「我的渠道」网点卡片星级变化**：选中某网点后，网点信息卡片中星级图标右侧展示该网点该周期相对上期的星级变化；随「我的渠道」顶部周期下拉切换刷新
- **星级 pills 切换**：详情页内可切换查看其它星级的网点
- **无数据星级**：数量为 0 的星级条目不可点

### 2.3 状态与异常

- **状态**：列表层正常 / 周期筛选态（团队长端「星级渠道」切换周期后数量与占比刷新）；详情页正常 / 周期筛选态 / 星级变化筛选态 / 空态 / 无上期数据（不显示变化图标，员工端「我的渠道」网点卡片同理）
  - 空态需区分两类并分别给文案：①该星级在当期本就无渠道；②该星级有渠道、但当前变化筛选下无匹配（此态应带「清除筛选 / 看全部」的回退入口）。具体文案已在页 PRD 细化
- **异常**：星级数据加载失败 → 展示加载失败提示与重试入口
- **回退**：从详情页返回 → 回到原列表页并保留原滚动位置；重新进入详情页 → 星级变化筛选回到默认态（全部）；周期不重置，进入时继承上游当前周期，页内切换不回写上游（员工端详情页进入时继承「我的渠道」周期、页内独立；团队长端详情页与其「星级渠道」列表周期独立，同为"继承 + 页内独立 + 不回写"）

### 2.4 跨页影响

- **入口页**：员工端「我的渠道」（渠道星级分布）、团队长端「团队星级渠道页」（星级分布）、团队长端「员工详情」（内嵌渠道星级分布）
- **结果页**：员工端「渠道星级详情页」（新增）、团队长端「星级渠道详情页」（改造）
- **被动影响页**：员工端「我的渠道」的网点信息卡片（新增星级变化图标）；其余模块本次不改造。与员工端「重点关注」的网点降级消息各自独立、不合并（消息＝推送提醒，变化图标＝页面内提示）。

### 2.5 仍未决项

无阻塞项。

## 五、验收标准

1. **主路径可完成**：在列表层（团队长端「星级渠道」可切周期）看到各星级数量 → 点击某星级条目 → 进入星级渠道详情页 → 看到该星级、该周期下的网点列表，且每个网点行右端展示相对上期的星级变化；员工端在「我的渠道」选中网点后，网点信息卡片星级图标右侧同样能看到该网点的星级变化
2. **关键分支成立**：逐条对应 2.2 —— 团队长端「星级渠道」切周期后数量与占比刷新；员工端「我的渠道」/ 团队长端「员工详情」跟随页面周期刷新；升星↑红 / 降星↓绿 / 无变化灰「—」/ 无上期数据不显示图标；无数据星级不可点；星级 pills 可切换且数量随星级变化筛选联动；两端详情页星级变化筛选生效；三处入口预置筛选正确；员工端「我的渠道」网点卡片变化图标随本页周期刷新
3. **状态与异常口径**：逐条对应 2.3 —— 该星级当期、当前变化筛选下无网点展示空态；加载失败有重试入口；返回列表保留位置；重进详情页星级变化筛选回到默认「全部」，周期进入时继承「我的渠道」当前周期、页内切换不回写「我的渠道」
4. **范围守界**：第四节列出的页面、模块、埋点与版本号均未发生变化

## 六、风险与依赖（可选）

- **前置依赖（阻塞数据侧）**：数仓需提供按周期（昨日 / 本周 / 自然月 / 本年）的星级快照或星级变化量（如 `starLevelDelta`）。当前仅有 `starLevel` 当期值、无历史快照，否则变化图标无数据源。**兜底口径**：数据未提供时，详情页网点行与员工端「我的渠道」网点卡片的星级变化图标整体不展示，其余功能不受影响。
- **前置依赖**：星级变化筛选需要每个网点有明确的变化类型（升星 / 降星 / 无变化）取值，员工端「我的渠道」网点卡片按网点粒度取该值。

- **风险**：切换周期需按周期拉取星级快照，需评估接口成本与首屏性能。
