一、需求背景

目标用户：员工端＝客户经理（本人，查看自己名下网点的经营结果）。

要解决的问题：员工在「我的渠道」未选择具体网点（全部网点汇总态）时，只能看到四张经营结果指标卡的汇总值（新增资产 / 新增有效户 / 新增开户数 / 经营积分），无法知道这些结果由名下哪个网点贡献、哪个网点在拖后腿。缺少从「汇总结果」下钻到「本人员工名下网点维度」的出口。

解决方式：在全部网点态下，四张经营结果指标卡变为可点击，进入新增的「名下渠道排名」二级页；该页复用团队长端「团队总览」二级页的按网点排名模式，把范围收敛到本人名下网点，让员工一眼看到名下各网点的结果排名。

竞品差异 / 品类惯例：不适用（本次为既有产品内的维度下钻增量，未做外部调研）。

AI 能力边界：不适用。

二、逻辑补齐摘要

2.1 主成功路径

员工进入「我的渠道」（全部网点态）→ 点击四张经营结果指标卡之一（新增资产 / 新增有效户 / 新增开户数 / 经营积分）→ 进入「名下渠道排名」二级页，页面预选该指标并展示本人名下网点按该指标的排名列表 → 点击某网点行就地展开该网点的渠道详情卡片 → 返回可回到「我的渠道」并保留原状态。

2.2 关键分支

  • 入口触发（仅全部网点态）：未选择具体网点 → 四张指标卡可点击，点击进入详情页并预选被点击的指标；已选中具体网点（单网点态）→ 四张指标卡不可点击、不提供入口（卡片保持现状视觉，无跳转）。
  • 页内切换指标：详情页中部保留 4 张指标卡（新增资产 / 新增有效户 / 新增开户数 / 经营积分），点击某张卡 → 排名列表按该指标刷新，卡选中态切换。
  • 范围收敛：排名列表仅包含本人名下网点，不出现他人名下网点；行内不再展示「所属员工」副信息（均为本人，冗余）。
  • 网点行点击：点击网点行 → 行下方展开该网点的渠道详情卡片（完整渠道名称 + 经营 4 项 + 过程 4 项）；再次点击 → 收起；同一时刻仅展开一行。　⚠️ 2026-11-09：卡片内容已调整为「完整渠道名称 + 渠道建档信息」，移除经营 4 项与过程 4 项，见修订记录
  • 时间周期联动：进入详情页继承「我的渠道」当前时间周期；页内可独立用时间周期下拉（昨日 / 本周 / 自然月 / 本年 / 考核月，2026-11-04 起扩为 5 项，详见《2026-11-04-考核月周期维度-spec.md》）切换，排名与展开卡片内容随之刷新。
  • 排序：保留团队总览二级页的排序切换（默认按名次；可切换为按数值升 / 降序）。

2.3 状态与异常

  • 状态：全部网点态（有入口，可点）／单网点态（无入口，不可点）；详情页内指标卡选中态（4 选 1）。
  • 空态：本人名下网点为空 → 详情页展示空态提示，无排名行。
  • 缺数据：某网点某指标缺数据 → 该行数值显示占位「—」；展开卡片内缺项同样显示「—」。
  • 回退：详情页返回 → 回到「我的渠道」，保留进入前的网点选择、时间周期与滚动位置（不重置）。

2.4 跨页影响

  • 入口页：员工端「我的渠道」——四张经营结果指标卡由「无点击」变为「全部网点态可点击进入详情页」。
  • 结果页（新建）：员工端「名下渠道排名」二级页。
  • 被动影响页：无。团队长端「团队总览」二级页及其按网点排名模式仅被复用、本身不改。
  • 不涉及：「名下渠道数」卡无入口；单网点态无入口；团队长端不新增该页。

2.5 仍未决项

  • 无阻塞项。

五、验收标准

  1. 入口正确（全部网点态）：员工在「我的渠道」全部网点态点击四张经营结果指标卡任一 → 进入「名下渠道排名」页且预选该指标；「名下渠道数」卡无入口。
  2. 入口正确（单网点态）：已选中具体网点时，四张卡均不可点击、无跳转。
  3. 范围正确：详情页排名列表仅含本人名下网点，不出现他人网点；行内不展示所属员工副信息。
  4. 模式一致：详情页具备时间周期下拉、4 张指标卡切换、排名列表与排序切换，形态与团队总览二级页按网点排名一致；无维度切换。
  5. 指标切换：页内点击不同指标卡，排名列表按该指标刷新。
  6. 行展开：点击网点行 → 行下方展开渠道详情卡片（完整名称 + 经营 4 项 + 过程 4 项）；再次点击收起；同一时刻仅一行展开。　⚠️ 2026-11-09：卡片内容已调整为「完整渠道名称 + 渠道建档信息」，移除经营 4 项与过程 4 项，见修订记录
  7. 周期联动：切换页内时间周期，排名与展开卡片内容同步刷新。　⚠️ 2026-11-09：展开卡片仅星级变化随周期刷新，建码日期·天数与关键人为静态档案，见修订记录
  8. 状态与回退：本人名下网点为空时展示空态；指标缺数据展示「—」；返回后回到「我的渠道」并保留原状态。
  9. 范围守界：第四节列出的项均未变化。

六、风险与依赖（可选）

  • 前置依赖（阻塞）：需本人员工名下网点级的经营结果指标数据（4 项）。现有口径中「我的渠道」四张卡在全部网点态为员工级汇总、单网点态为单点值，尚未提供"本人名下网点"的集合及其分网点数值。兜底：数据未到位时，原型按演示数据派生（本人名下网点集合与名下渠道数对齐），研发阶段需补网点级聚合接口。
  • 依赖：详情页结构复用团队长端「团队总览」二级页（overview-detail）的按网点排名实现；样式复用各端既有指标卡 / 排名行 / 渠道详情卡片样式，避免二次分叉。
  • 风险：「我的渠道」四张卡由不可点变为可点，需回归确认不影响该页其它交互（网点选择、时间周期、过程跟进等）。
  • 风险：本人名下网点集合与现有演示数据（网点选择器 5 个网点、名下渠道数 8）口径不一致，原型阶段需明确并统一演示口径。
