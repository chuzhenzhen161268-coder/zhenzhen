## 一、需求背景

**目标用户**：员工端＝客户经理；团队长端＝团队长。

**要解决的问题**：员工端 / 团队长端的「渠道星级详情页」，以及团队长端「团队总览 · 查看完整排名（按网点）」中，渠道（网点）名称为长名称、被省略号隐藏看不到全称；且这些列表没有就地查看"该渠道经营 / 过程指标"的入口。

**解决方式**：在上述渠道行下增加**行内展开的渠道详情卡片**，作为①长名称的完整查看出口、②该渠道经营 / 过程指标的就地查看入口。整行点击触发。

**AI 能力边界**：不适用。

## 二、逻辑补齐摘要

### 2.1 主成功路径

在任一适用列表，用户点击某条**渠道（网点）行** → 该行下方原地展开「渠道详情卡片」→ 卡片内完整展示网点全称 + 该渠道的经营指标与过程指标 → 再次点击该行 → 收起。

### 2.2 适用范围与关键规则

- **适用范围（4 处）**：
  1. 员工端 · 渠道星级详情页（渠道行）
  2. 团队长端 · 渠道星级详情页（渠道行）
  3. 团队长端 · 团队总览 · 查看完整排名 · **仅「按网点」维度**（首页 Top4 预览区 + 「查看完整排名」完整页）　⚠️ 2026-11-09 卡片内容已调整，见修订记录
  4. 员工端 · 名下渠道排名（2026-11-04 追加，见《2026-11-04-名下渠道排名-spec.md》）　⚠️ 2026-11-09 卡片内容已调整，见修订记录
- **触发方式**：**整行点击**。
  - 点击渠道行 → 卡片在该行下方原地展开；再次点击该行 → 收起。
  - 不新增行尾箭头。
- **点击行为（按页面区分）**：
  - 星级详情页（员工端 / 团队长端）：整行点击＝展开 / 收起卡片（原为占位 toast，本次替换）。
  - 团队总览 · 按网点维度：整行点击＝展开 / 收起卡片，**不跳转员工详情**。
  - 团队总览 · 按员工维度：**无卡片**；整行点击＝进入员工详情（现状不变）。
- **卡片内容**（自上而下）　⚠️ 2026-11-09：以下口径现仅「渠道星级详情页」两处适用；「团队总览 · 按网点」与「名下渠道排名」已改为「完整渠道名称 + 渠道建档信息」，见修订记录：
  1. **完整渠道名称**：不发生省略号隐藏，完整展示全称。
  2. **经营指标（4 项）**：银行渠道新增资产 / 银行渠道新增有效户 / 银行渠道新增开户数 / 银行渠道经营积分；每项含数值 + 单位 + 变化（↑红 / ↓绿 / —持平）。
  3. **过程指标（4 项）**：拜访次数 / 活动次数 / 需求总数 / 需求未满足；其中「需求未满足」数字为红色，其下方再以红色小字标注「N 条紧急」。
- **不包含**：员工级指标「名下渠道数」不得出现在卡片（语义为员工级，网点维度不可用）。
- **周期联动**：卡片内各项指标随页面顶部「时间周期」下拉（昨日 / 本周 / 自然月 / 本年 / 考核月，2026-11-04 起扩为 5 项，详见《2026-11-04-考核月周期维度-spec.md》）切换刷新，与该页其余指标口径一致。　⚠️ 2026-11-09：该规则现仅「渠道星级详情页」两处适用；调整为建档信息的两处，仅**星级变化**随周期刷新
- **卡片样式**：经营指标以 2×2 网格、过程指标以 4 项行排布，视觉沿用各端既有指标卡样式。
- **展开互斥（建议）**：同一列表同时仅展开一行；点击另一行时，原展开行收起。

### 2.3 状态与异常

- **状态**：收起（默认）/ 展开（同时仅一行，见上）
- **无数据**：某指标缺数据 → 该项显示占位「—」；经营与过程指标全部缺数据 → 卡片仅展示完整渠道名称，并给轻量说明"暂无指标数据"
- **回退**：团队总览展开态下切换排名维度 → 卡片收起（因「按员工」维度无卡片）

### 2.4 跨页影响

- **受影响页**：
  1. 员工端 · 渠道星级详情页
  2. 团队长端 · 渠道星级详情页
  3. 团队长端 · 团队总览 · 查看完整排名（首页 Top4 + 完整排名页，按网点维度）
- **被动影响**：行点击行为变化（星级详情页原 toast 被替换；团队总览按网点维度不再跳员工详情）；展开时行高变化
- **不涉及**：其它列表本轮不加卡片

### 2.5 仍未决项

- 卡片内指标是否提供下钻（建议：本轮不提供）

## 五、验收标准

1. **主路径可完成**：3 处列表中点击渠道行 → 行下方展开渠道详情卡片 → 完整展示网点全称与经营 4 项、过程 4 项 → 再次点击收起
2. **触发正确**：整行点击触发展开 / 收起；同一列表同时仅展开一行
3. **点击行为正确**：星级详情页整行点击＝展开卡片（不再是占位 toast）；团队总览「按网点」点击行不跳员工详情；「按员工」无卡片、点击行进员工详情
4. **字段正确**：经营＝新增资产 / 新增有效户 / 新增开户数 / 经营积分；过程＝拜访次数 / 活动次数 / 需求总数 / 需求未满足；不含「名下渠道数」　⚠️ 2026-11-09：该项现仅「渠道星级详情页」两处适用；「团队总览 · 按网点」与「名下渠道排名」改为「完整渠道名称 + 渠道建档信息」
5. **周期联动**：切换页面顶部「时间周期」，卡片指标同步刷新
6. **状态与异常**：指标缺数据显示「—」；全缺时卡片仅展示完整名称
7. **范围守界**：第四节列出的项均未变化

## 六、风险与依赖（可选）

- **前置依赖（阻塞）**：需**网点级**（渠道级）经营与过程指标数据。现有口径中这些指标多为团队 / 员工维度汇总，是否已按网点粒度下钻需研发确认。**兜底**：数据未到位时卡片降级为"完整渠道名称 + 暂无指标数据"。
- **依赖**：卡片指标样式建议复用各端「团队总览」既有指标卡样式，避免二次分叉。
- **风险**：星级详情页与团队总览的行点击行为均发生变化（占位 toast 被替换 / 不再跳员工详情），需回归确认不影响其它入口。
- **风险**：卡片展开改变行高，需确认不影响列表密度、排序与滚动位置。
