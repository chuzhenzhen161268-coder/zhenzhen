1. 页面定位

1.1 核心目标

为客户经理和投顾提供独立的存量合格投资者临近到期提醒服务清单。在同一页面完成客户搜索与分组筛选、认证和客户画像查看、沟通素材准备、完整沟通思路查阅、话术编辑及电话/企微服务记录；页面结构、视觉和基础交互继承既有高净值客户服务清单，但本场景客户、筛选、服务状态及服务记录独立维护。

1.2 入口来源

  • 员工消息盒子的本场景认证临近到期自动任务入口（首次进入距到期日 ≤ 30 个交易日窗口时提醒一次）。
  • GWork 自由圈客后的本场景清单入口。
  • GWork 输入“给我存量合格投资者临近到期服务清单”后的快捷生成入口。

1.3 出口去向

  • 点击“客户详情”打开既有客户全量视图系统。
  • 点击电话外呼发起既有电话服务。
  • 点击企微单聊进入既有企微单聊能力。
  • 点击企微一键群发打开本页群发弹框，不跳转到资产升级、资产降级或其他高净值服务清单。
  • 完成服务后留在本清单，当前客户移至左侧列表底部。

2. 模块结构

2.1 模块清单

模块ID 模块名称 类型 作用说明
M1 清单元信息 左侧客户列表头部 来源按实际入口展示“员工消息”或“GWork 快捷生成”，同时显示生成时间；不再单独占用右侧卡片。
M2 客户搜索、筛选与列表 左侧滚动 标题旁显示当前清单客户总数；按姓名/资金账号、认证资格、私募持仓、资配方案状态筛选客户；展示待服务与已完成客户。
M3 群发工具条 列表操作 提供本场景企微一键群发入口及当前场景防重标记。
M4 客户基础信息与待处理任务 右侧顶部固定 复用 AI+服务清单基础信息、客户详情、电话外呼及 ISMP 待处理任务设计；切换客户时摘要区不随下方内容滚动。
M5 认证与客户画像 下方单列内容区 展示近20日日均净资产、KYC、私募/资管认证、持仓及历史认购/配置记录；与沟通相关内容统一放在顶部客户信息下方的一列中滚动。
M6 沟通素材 下方单列内容区 仅展示适用的一页通及其实时获取状态；不展示财富月刊、大 C 方案或内部指引。
M7 完整沟通思路 下方单列内容区 按当前客户所属 8 类分组键，仅展示需求表中对应的一组完整业务原文；内部 PDF 指引与适用的一页通均以文件名链接穿插其中，点击后预览。
M8 服务话术 下方单列内容区 展示合规初审状态和摘要式话术，支持直接编辑、失焦保存及复制。
M9 服务操作 右侧底部固定 记录服务内容，并完成电话/单聊服务或触发群发后的服务结果回写。
M10 企微群发弹框 页面浮层 支持千人一面、千人千面、客户移除、话术查看和发送结果。
M11 完成服务确认弹框 页面浮层 确认服务记录并更新本场景完成状态。

模块 M2：客户搜索、筛选与列表

元素ID 元素名称 类型 内容/数据 交互行为
M2-E0 客户列表标题与数量 标题/弱标签 客户列表、当前清单客户总数 数量展示为“48位”，固定显示清单总人数，不随搜索或筛选结果变化。
M2-E1 姓名/资金账号搜索 搜索输入框 占位提示“搜索姓名或资金账号” 输入后按姓名、资金账号模糊匹配并实时刷新列表；与所有筛选条件叠加；支持清空。
M2-E2 资产等级筛选 紧凑下拉按钮/选项浮层 与三维筛选并排显示“资产等级：当前选项”；选项为全部、1000万以上、500-1000万、300-500万、300万以下 默认“全部”；点击后在按钮下方展开单选选项，选中后入口显示当前等级并立即刷新客户列表。资产等级与认证、持仓、资配条件及搜索之间为“且”关系。
M2-E3 三维条件筛选入口 紧凑按钮/浮层 与资产等级下拉并排显示“筛选”按钮；存在已启用条件时显示数量徽标 默认收起三个下拉条件；点击按钮后，在按钮下方靠右展开浮层，再选择认证、持仓、资配条件。浮层内提供“重置”；点击浮层外部或按 Esc 收起。资产等级选项浮层与三维筛选浮层互斥展开。
M2-E4 认证条件筛选 下拉筛选 全部、符合、不符合 默认“全部”；依据客户当前认证资格筛选。选项位于“筛选”浮层中。
M2-E5 私募持仓筛选 下拉筛选 全部、有持仓、无持仓 默认“全部”；仅以当前私募持仓判断，资管持仓不参与。选项位于“筛选”浮层中。
M2-E6 资配方案筛选 下拉筛选 全部、已做过、未做过 默认“全部”；依据当前客群分组所用的资配方案状态筛选。数据不可用时不归入“已做过”或“未做过”，但“全部”仍保留该客户。选项位于“筛选”浮层中。
M2-E7 筛选组合逻辑 交互规则 资产等级 + 认证条件 + 私募持仓 + 资配方案 + 搜索 三个客群维度可独立选择，用户可自由组合为 8 类中的任意组合；每个维度内部单选，选“全部”不限制该维度。不同维度和姓名/账号搜索之间取“且”。筛选变化后立即刷新列表，不改变服务状态。
M2-E8 客户列表项 列表项 姓名、资金账号、认证资格摘要、当前私募持仓状态、资配方案状态、近20日日均净资产 点击后切换右侧当前客户；首次加载默认选中排序首位待服务客户。若有剩余交易日展示需求，作为圈客依据保留在数据层，不在本期新增页面字段。
M2-E9 已完成客户分组 分割标签/样式 已完成服务客户与完成时间 已完成客户置灰、置于列表底部，仍可点击查看详情和服务记录。
M2-E10 无匹配状态 空状态 当前搜索词及筛选条件 无匹配时替换列表区域，不影响清单头部和右侧当前已选客户。

默认排序：待服务客户在前、已完成客户在后；待服务客户按当前服务优先级排序。优先级细则未在本期确认，页面不提供员工手动排序入口。

6. 页面状态

状态 触发条件 UI 表现
正常态 清单、画像和话术正常返回 展示待服务客户列表及当前客户详情。
清单加载态 清单仍在生成或加载 左侧客户列表显示骨架占位，右侧不展示可执行服务动作。
空清单 接口成功但无命中客户 左侧展示空清单说明及本次入口/条件，右侧展示空详情占位。
无匹配客户 搜索或筛选无结果 左侧仅替换为无匹配状态，保留筛选和清空入口。
认证数据异常 认证数据获取失败 当前客户认证区展示异常说明与重试；不静默移除客户。
画像部分缺失 部分画像字段无数据 对应字段展示“--”或空状态；话术不得引用缺失字段。
动态材料失败 思路中点名且资配状态匹配的一页通获取失败 对应素材卡与思路内文件名显示不可用状态和重试入口；不阻断画像、话术及服务操作。财富月刊与大 C 方案不属于本场景素材。原型静态示例图不得标注为线上获取成功。
话术生成/初审失败 生成或首次合规初审失败 话术区展示失败原因及重试；该话术不可用于触达。
已完成服务 员工确认完成服务 客户置灰并移入已完成分组，详情保留已完成记录；清单再次生成时回显已服务状态。
认证临近到期提醒 每日 5:00 取 T-1 日数据执行；客户首次进入距到期日 ≤ 30 个交易日窗口 每日 9:00 定时推送；每个客户/认证/有效期仅首次进入窗口提醒一次，交易日继续减少不重复推送。使用交易日历，到期当天算未到期。
认证数据更新 客户续期或有效期被修正 下次生成清单按最新数据重新判断；修正后不满足条件的不再圈选。
群发部分成功 群发回执存在成功和失败客户 弹框展示逐客户结果；成功客户标记已触达，失败客户保留可重试状态。

7. 备注/设计资源

  • 页面视觉、基础信息、待处理任务、电话外呼、企微单聊、服务记录和群发结果交互，继承既有 AI+高净值客户服务清单的设计基线。
  • 8 类分组原文、素材分类与数据依赖以 需求规格（Spec） 为准。
  • 两份 PDF 是内部沟通参考资料，不是客户发送材料；大 C 方案为五档独立内容，与资产配置一页通不同，本场景不展示或发送大 C 方案及财富月刊。
  • 业务待确认仅剩历史认购与配置记录的查询时间范围；自动任务调度、资配记录判断及群发规则以已确认口径执行。交易日历来源、接口失败回退等工程细节由研发按现有平台能力确定。
