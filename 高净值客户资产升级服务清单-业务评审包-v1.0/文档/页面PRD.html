1. 页面定位

1.1 核心目标

为客户经理提供一张已生成完成的高净值客户资产升级服务清单。员工可按资产等级筛选客户，在右侧查看 AI+服务清单同款客户基础信息与 ISMP 待处理任务，阅读结构化客户画像和合规审核通过的话术，并完成电话、企微单聊、企微一键群发及服务记录。

1.2 入口来源

  • 员工消息盒子中的自动任务清单入口。
  • WorkBuddy 自由圈客或“给我高净值客户资产升级服务清单”快捷生成后的清单入口。

1.3 出口去向

  • 点击“客户详情”打开客户全量视图系统，沿用 AI+服务清单的单点跳转。
  • 点击电话外呼按钮发起既有电话服务。
  • 点击企微一键群发进入既有群发流程，沿用 AI+服务清单的防重发规则。
  • 完成服务后留在本清单并更新客户完成态；不新增独立结果页。

2. 模块结构

2.1 模块清单

模块ID 模块名称 类型 作用说明
M1 清单信息头部 左侧客户列表顶部 展示“客户列表”、本次清单总人数、来源和生成时间；总人数不随搜索和筛选变化，不展示生成完成状态。
M2 客户列表 左侧滚动 展示客户及资产等级筛选；按默认优先级排序，已完成服务客户置灰并置于底部。
M3 群发工具条 列表操作 放置企微一键群发入口，沿用 AI+服务清单的选择、防重、发送和结果回写规则，并新增千人一面、千人千面两种发送模式。
M4 客户基础信息 右侧固定顶部 完全复用 AI+服务清单的基础信息模块与交互；客户切换时更新模块内容，不随右侧详情滚动。
M5 ISMP 待处理任务 固定顶部基础信息内 查询并展示当前客户在 ISMP 的待处理任务数量和任务名称，沿用既有任务查看/处理交互；展开任务列表保持在顶部模块内，内容过多时任务列表自身滚动。
M6 客户画像 右侧独立滚动区 展示近20日日均净资产、私募与资管两类合格投资者认证、持仓与产品结构、交易行为和账户盈亏。
M7 沟通素材 右侧独立滚动区 按资产跃迁路径展示信件、权益清单和资产配置一页通；默认全部勾选，允许取消单份。
M8 沟通思路 右侧独立滚动区 展示分层沟通框架供投顾参考，不进入发送内容。
M9 服务话术 右侧独立滚动区 展示合规审核通过状态、完整话术、人工编辑状态和一键复制。
M10 服务操作 右侧底部 提供服务内容记录和完成服务按钮，沿用 AI+服务清单的完成服务交互。

模块 M3：群发工具条

元素ID 元素名称 类型 内容/数据 交互行为
M3-E1 企微一键群发 主按钮 企微一键群发 放在左侧客户列表顶部；进入选择模式后复用 AI+服务清单群发分类、选择、确认、防重和发送结果规则。
M3-E3 群发模式切换 分段控件 千人一面、千人千面；默认千人一面 切换模式不丢失已选客户、素材取消和话术编辑状态。
M3-E4 千人一面分组 分组弹窗 按资产档位、资产跃迁路径、当前发送素材组合自动拆组；股票/理财不作为拆分条件 同一组展示统一素材和统一话术；不同组不可混发；每组单独发送，发送完成后可进入下一组。
M3-E5 千人千面列表 客户明细列表 每位客户的资产档位、跃迁路径、个性化话术和可发送素材 每位客户可单独查看/编辑话术、取消素材和移除客户；一次确认后逐客户发送。

M9-A 大模型生成约束

规则项 生成要求 禁止项
档位依据 先按客户资产跃迁路径匹配对应档位的完整沟通思路；各档话术的服务权益、沟通重点和收口方向须与该沟通思路一致。 不直接复制或逐条复述内部沟通思路。
画像取值 从风险等级、持仓结构、交易行为、账户盈亏、合格投资者认证状态、待处理任务中选择 1–2 个最相关的切入点。 不堆砌画像字段，不将具体资产金额作为沟通内容。
话术结构 固定为三个自然段：①以研究观点、账户复盘或服务权益作价值开场；②说明可提供的服务或复盘方向；③提出 1–2 个了解客户需求的问题，并给出可先了解、暂不操作的轻量邀约。 不生成完整内部讲稿式长文，不教育、不说服、不施压客户。
合规表达 不承诺收益；涉及私募或资管计划时，使用“以合格投资者认证和适当性匹配结果为前提”的中性表述。 不展示模型判断过程、内部规则或未验证的适配结论。
群发适配 千人一面仅对同一资产档位、跃迁路径和素材组合生成同一摘要话术；千人千面在相同框架下按客户画像生成不同摘要。 不将不同档位、跃迁路径或素材组合的客户混用同一话术。

6. 页面状态

状态 触发条件 UI 表现
正常态 清单已生成且客户数据加载完成 展示头部、左侧客户列表、右侧当前客户信息、画像、沟通素材、沟通思路、话术和服务操作。
搜索无匹配 姓名/资金账号关键词与当前资产等级筛选的交集为空 左侧列表区展示“未找到匹配的客户”，保留搜索框和资产等级筛选，右侧当前客户详情不自动清空。
无客户 本次清单没有命中客户 左侧展示“暂无客户数据”，不展示空客户详情。
任务加载中 首次选中客户，ISMP 任务尚未返回 基础信息卡任务区展示加载占位；其他客户画像内容可正常查看。
任务为空 ISMP 返回任务总数为 0 任务区展示“暂无待处理任务”。
任务查询失败 ISMP 请求失败 任务区展示失败提示和重试入口，不影响其他画像与话术展示。
画像字段缺失 单项画像数据为空 对应字段展示“--”，不使用模型推断补齐。
话术可用 话术生成完成且合规审核通过 展示完整话术、一键复制和编辑入口。
话术人工已编辑 员工修改并保存话术 展示“人工已编辑”；允许复制和触达，不触发二次合规审查。
服务已完成 员工完成服务并提交记录 当前客户置灰并移至列表底部，展示完成时间；仍可查看详情和历史服务记录。
群发防重 客户在当前场景已群发成功 展示“已群发”标记和发送时间；重新进入群发选择时默认排除，手动点击时提示“该客户当前服务场景已群发成功，不可重复发送”；发送前再次校验，避免并发或状态未刷新导致重复发送。
千人一面分组 选中客户存在不同资产档位、跃迁路径或素材组合 系统自动拆分为多个群发组；股票/理财不作为拆分条件。
千人千面 员工选择个性化发送 每位客户独立展示话术和素材；发送结果按客户回写，失败客户可单独重试。
动态素材获取失败 资产配置平台返回失败 对应一页通显示“暂不可用，可重试”，不可勾选和发送；固定素材、沟通思路、话术和其他服务动作不受影响。
素材部分取消 投顾取消单份素材 卡片显示未勾选；群发确认弹框同步移除该素材；不影响其他素材和话术。
认证数据缺失/过期 认证平台返回私募或资管认证字段缺失、查询失败或有效期已过 按认证类型分别展示；缺失字段展示“--”，有效期已过时展示“已过期”及平台返回日期，不由另一类认证状态或模型补齐。
AI+助手数据异常 AI+助手交易/盈亏数据查询失败 展示数据不可用和重试入口，不使用本场景自算数据替代。
全量圈客 WorkBuddy 命中任意数量客户 直接按实际命中人数生成，不展示 100 人上限判断、确认、排序选择或超时兜底。

7. 备注/设计资源

  • 基础信息、电话外呼、待处理任务、完成服务、企微一键群发及防重发均以 AI+服务清单为交互基线。
  • 本页面不展示生成进度、生成失败或生成重试状态；进入页面表示本次清单已完成生成。
  • 持仓与产品结构采用分层表格；交易行为和账户盈亏分别采用独立表格。
  • 沟通素材默认全选但允许取消；对客发送内容为当前对客话术与勾选素材，沟通思路仅供投顾参考。
  • 沟通思路默认展开第一步、其余步骤按标题收起，步骤标题右侧使用方向箭头指示展开状态；支持一键展开/全部收起和单步展开；展开后展示完整原文，不摘要、不删减，切换客户后恢复“第一步展开、其余步骤收起”。不展示“完整原文”标签。
  • 左侧客户列表在资产等级筛选上方提供姓名/资金账号合并搜索；输入实时筛选，可清空，并与资产等级筛选叠加使用。
