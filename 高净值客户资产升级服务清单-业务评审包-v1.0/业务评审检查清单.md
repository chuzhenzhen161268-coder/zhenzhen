# 高净值客户资产升级服务清单｜业务评审检查清单

> 使用方式：建议业务负责人在会议中逐项确认。所有 P0 项通过且唯一待确认口径完成拍板后，进入技术评审。

## 一、业务目标与范围

- [ ] P0：确认新增独立「高净值客户资产升级服务清单」，与现有 AI+服务清单并列。
- [ ] P0：确认页面和交互以 AI+服务清单为母版，仅替换资产等级筛选、画像、话术和圈客逻辑。
- [ ] P0：确认本期不修改消息盒子入口、不新增跨场景防重及历史清单查询。

## 二、圈客与生成规则

- [ ] P0：确认自动任务每日 15:30 执行，覆盖三个资产档位且不设人数上限。
- [ ] P0：确认 WorkBuddy 自由圈客只执行员工明确提出的条件和排除规则。
- [ ] P0：确认 WorkBuddy 快捷生成默认圈选三个档位，并排除近90天本场景已成功联系客户。
- [ ] P0：确认 WorkBuddy 超过100人时等待确认1分钟，可全部生成或按排序生成前100人。
- [ ] P0：确认1分钟未回复时按默认排序生成前100人。
- [ ] P0：拍板自动任务90天排除使用“已成功联系”还是“已推送”。

## 三、客户列表与信息

- [ ] P0：确认左侧资产等级筛选为全部、1000万以上、500–1000万、300–500万。
- [ ] P0：确认客户列表展示姓名、资金账号、风险等级、近20日日均净资产。
- [ ] P0：确认已完成服务客户置灰并移动到列表底部，仍可查看详情。
- [ ] P0：确认客户基础信息与 ISMP 待处理任务完全复用 AI+服务清单。

## 四、客户画像

- [ ] P0：确认展示近20日日均净资产及私募合格投资者认证状态。
- [ ] P0：确认持仓按资产大类汇总，并支持展开查看标的、市值与仓位、收益额、持有天数。
- [ ] P0：确认近6个月股票、ETF、场外基金交易次数分开展示。
- [ ] P0：确认近1月、近3月、近6月账户盈亏分开展示。
- [ ] P0：确认画像缺失字段只展示“--”，不由大模型补齐。

## 五、话术与服务操作

- [ ] P0：确认初始话术必须合规审核通过后才可使用。
- [ ] P0：确认人工编辑后显示“人工已编辑”，无需再次审核。
- [ ] P0：确认企微一键群发及防重规则完全沿用 AI+服务清单。
- [ ] P0：确认电话以员工点击“完成服务”为成功服务口径。
- [ ] P0：确认企微群发以发送成功为成功联系口径。
- [ ] P0：确认企微单聊以员工手工标记已触达或已完成服务为成功联系口径。

- [ ] 自动任务90天排除口径已拍板并记录。
- [ ] 无其他阻塞研发需求澄清的问题。
