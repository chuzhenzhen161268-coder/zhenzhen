# 产品需求文档：高净值客户资产升级服务清单

## 1. 项目概览

**项目名称**：高净值客户资产升级服务清单  
**平台类型**：PC Web

### 背景与目标

客户因资金转入或账户盈利达到更高资产等级后，客户经理需要及时识别客户、理解账户与风险画像，并按对应等级完成升级服务。当前圈客、画像查看、话术准备和触达记录分散，难以形成持续、可追踪的服务闭环。

本期新建独立的高净值客户资产升级服务清单场景，统一承接每日自动任务和 WorkBuddy 主动查询。系统完成圈客、画像、分层沟通思路、沟通素材、合规初审话术和服务结果回流，帮助员工开展分层经营。本次沟通能力属于未上线前的 1.0 需求完善，不单独升版本。

### 目标用户原型

- **用户特征**：负责自己名下客户经营的客户经理或投顾，日常使用内部服务清单、电话和企微工具。
- **底层动机**：以较少的准备成本识别真正需要升级服务的客户，并据此完成有针对性的服务。
- **典型场景**：员工收到自动生成的服务清单，或在 WorkBuddy 主动查询目标客群后，查看画像和话术并开展服务。

### 核心价值主张

为客户经理 / 投顾解决高净值客户升级经营中圈客、服务准备和结果追踪分散的问题，提供可直接执行的服务清单与场景化服务闭环。

### 成功判定标准

- **用户侧**：员工可从自动任务或 WorkBuddy 生成并打开可服务客户清单，初审通过的客户可直接进入触达。
- **业务侧**：可按资产档位统计清单生成、完成服务、财富诊断 / 配置复盘预约及进入 1+N 专家团队的数据。
- **质量侧**：未初审通过的话术不能用于触达；已联系客户能按场景准确参与近 90 天排除。

## 2. 产品发现结论

### 价值层级分析

| 价值层级 | 表面需求 | 底层动机 | 隐含假设 |
| --- | --- | --- | --- |
| 精准识别 | 按资产升级条件自动或主动圈客 | 将有限服务资源投入更需要经营的客户 | 资产、历史推送与服务结果数据能准确识别和回流 |
| 服务准备 | 批量提供客户画像与合规初审话术 | 降低服务前的信息整理与话术准备成本 | 画像完整度足以支撑个性化服务建议 |
| 服务闭环 | 记录触达与服务结果，并参与后续排除 | 避免重复经营并衡量经营效果 | 电话、企微等工具能够携带场景标识回流结果 |

### 风险评估

| 价值层级 | 价值风险 | 可用性风险 | 可行性风险 | 商业可行性风险 |
| --- | --- | --- | --- | --- |
| 精准识别 | 中：自动任务的 90 天排除口径尚待业务统一 | 低：自动与主动入口均贴合当前工作方式 | 中：依赖圈客、历史记录数据准确性 | 低：服务对象与既有高客经营策略一致 |
| 服务准备 | 低：画像和话术直接服务于员工准备动作 | 中：生成失败或内容质量会影响采用 | 中：依赖画像、模型与合规服务协同 | 低：减少重复人工准备成本 |
| 服务闭环 | 中：员工是否完整标记单聊与电话服务结果需验证 | 中：不同渠道的完成状态定义不同 | 中：需要触达工具按场景回写 | 低：可直接支撑经营过程和结果统计 |

## 3. 产品结构图

### 核心功能清单

| 功能 | 优先级 | 一句话说明 |
| --- | --- | --- |
| 双入口圈客 | P0 | 支持自动任务、WorkBuddy 自由圈客与快捷生成。 |
| 大批量确认与超时兜底 | P0 | WorkBuddy 命中超过 100 人时，支持确认全量生成或超时按默认排序生成前 100 人。 |
| 批量画像与话术生成 | P0 | 对入选客户批量获取画像、生成话术并完成统一合规初审。 |
| 高净值客户服务清单 | P0 | 按资产档位与资产规模展示可服务客户、状态和优先级。 |
| 客户画像与话术准备 | P0 | 查看画像、分层沟通思路、沟通素材，使用或编辑话术、识别失败并重试。 |
| 沟通素材与发送组合 | P0 | 按资产跃迁路径匹配信件、权益清单和配置一页通，默认全选并允许取消；单聊和群发时同步当前勾选素材。 |
| 企微群发双模式 | P0 | 支持千人一面分组群发与千人千面个性化群发；股票/理财不作为拆分条件。 |
| 触达与服务结果回流 | P0 | 回流电话完成服务、企微群发成功和企微单聊人工标记结果。 |
| 场景经营数据输出 | P1 | 向 ABI 输出场景 ID 与服务结果。 |

### 页面组织方式

采用无新增全局导航的列表-详情结构。员工从既有消息盒子或 WorkBuddy 进入对应的本次服务清单，在同一页面完成客户选择、画像查看、话术准备和触达。

```text
既有入口（消息盒子 / WorkBuddy）
└── 高净值客户资产升级服务清单
    ├── 客户列表与筛选结果
    └── 客户详情
        ├── 客户画像
        ├── 沟通素材 / 投顾沟通思路
        ├── AI 初审话术 / 人工编辑话术
        └── 电话、企微单聊、企微群发及服务状态
```

### 本期不做

| 本期不做 | 理由 |
| --- | --- |
| 修改 AI+选好股服务清单 | 两个场景并列，本期不影响既有规则或数据。 |
| 修改消息盒子入口 | 复用现有自动任务入口即可满足触达需求。 |
| 员工编辑话术后二次合规审核 | 本期仅接入初审结果，避免新增审批链路。 |
| 新增电话、企微单聊、企微群发之外的触达渠道 | 先覆盖既有工具；其他渠道需具备明确服务完成回流后再评估。 |
| 历史清单查询、跨场景防重和统一频控 | 不影响当前场景的最小服务闭环。 |

## 4. 业务流程图

**核心业务流程**

```mermaid
flowchart TD
    Start([开始]) --> Entry{触发入口}

    Entry -->|自动任务 每日15:30| Auto[按三个资产档位圈客<br/>暂按90天已推送排除]
    Entry -->|WorkBuddy 自由圈客| Free[解析员工指定的资产、画像、排序与排除条件]
    Entry -->|WorkBuddy 快捷生成| Quick[按三个资产档位圈客<br/>默认排除90天内本场景已联系客户]

    Free --> Parsed{条件可解析且受支持？}
    Parsed -->|否| Clarify[说明未识别条件<br/>请求员工修改或确认] --> Free
    Parsed -->|是| Match[生成命中客户集合]

    Auto --> Match
    Quick --> Match
    Match --> Empty{是否有客户？}

    Empty -->|否| EmptyResult[展示空结果与本次条件] --> End([结束])
    Empty -->|是，自动任务| Batch[批量查询客户画像]
    Empty -->|是，WorkBuddy| Limit{命中是否超过100人？}

    Limit -->|否| Batch
    Limit -->|是| Confirm[展示人数与当前排序<br/>等待员工确认，最长1分钟]
    Confirm -->|确认全部生成| Batch
    Confirm -->|指定排序并生成前100人| Top100[按指定排序取前100人] --> Batch
    Confirm -->|1分钟未确认| Default100[按默认排序取前100人<br/>反馈默认执行] --> Batch

    Batch --> Generate[批量生成分档个性化话术]
    Generate --> Review[统一合规初审]
    Review --> Ready{客户是否生成并初审通过？}

    Ready -->|是| List[生成独立服务清单<br/>展示列表、画像、可用话术与状态]
    Ready -->|部分否| Partial[标记失败客户并支持重试] --> List
    Ready -->|全部否| Failed[展示生成失败状态并支持重试] --> End

    List --> Employee[员工查看画像、沟通思路、素材与话术<br/>素材默认全选，可编辑话术，无需二审]
    Employee --> Contact{选择触达方式}
    Contact -->|电话| Phone[员工完成服务]
    Contact -->|企微群发| BroadcastMode{选择群发模式}
    BroadcastMode -->|千人一面| OneToMany[按资产档位、资产跃迁路径、当前素材组合拆组<br/>同组共享话术和素材，逐组确认发送]
    BroadcastMode -->|千人千面| ManyToMany[逐客户展示个性化话术和素材<br/>可单独编辑或取消素材，一次确认后逐客户发送]
    Contact -->|企微单聊| Chat[员工标记已触达或已完成服务]
    Contact -->|暂不触达| Keep[保留当前清单与服务状态] --> End

    Phone --> Writeback[携带场景 ID 回流服务结果]
    OneToMany --> GroupWriteback[回传各组发送结果]
    ManyToMany --> PersonalWriteback[回传逐客户发送结果]
    GroupWriteback --> Writeback
    PersonalWriteback --> Writeback
    Chat --> Writeback
    Writeback --> Done[更新本场景触达/服务状态<br/>纳入90天已联系判断] --> End
```

**沟通素材规则**：素材由资产跃迁前后档位决定。300 万以内→300–500 万展示 300 万信件和股票/理财权益清单；300–500 万→500–1000 万展示 500 万信件和 500 万资产配置一页通；直接跨档时覆盖中间权益；500–1000 万→1000 万以上展示 1000 万信件和 1000 万资产配置一页通；300 万以内直接到 1000 万以上时覆盖 300 万权益。素材进入清单时默认全部勾选，投顾可以取消单份；配置一页通进入清单时从资产配置平台实时获取，当前清单会话内沿用同一版本，获取失败时该素材不可发送但不影响其他服务动作。沟通思路仅供投顾参考，不进入对客发送内容。

**企微群发模式规则**：默认进入“千人一面”，系统按客户资产档位、资产跃迁路径和当前勾选素材组合自动拆组；股票/理财客户不作为拆分条件，同组客户共享同一份对客话术和素材组合，员工逐组确认发送，完成一组后可继续下一组。切换为“千人千面”后，每位客户独立展示其个性化对客话术和当前素材选择，员工可以单独编辑话术、取消素材或移除客户，确认后系统逐客户发送并回写成功/失败结果。沟通思路始终只供投顾参考，不进入任何群发内容；沿用 AI+服务清单既有防重发规则。

**流程关键口径**：自动任务每日 15:30 生成全量符合条件客户且不设人数上限。WorkBuddy 超过 100 人时，员工可确认全量生成或指定前 100 人；等待 1 分钟未确认时，系统按默认排序生成前 100 人。自动任务的近 90 天排除暂按“已推送”执行，是否统一为“已成功联系”留待业务评审决定。
