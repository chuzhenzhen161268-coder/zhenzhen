# 高净值客户资产升级服务清单：五档大 C 方案素材 — 需求规格（Spec）

**产品名称**：高净值客户资产升级服务清单  
**模式**：迭代（iterate）  
**平台类型**：Web 网页  
**日期**：2026-10-27  
**迭代版本号**：v1.0（产品上线前的需求完善，不升级正式版本）  
**流程设计要求**：跳过（沿用现有单客户素材确认与企微群发流程，仅增加一种客户级素材）

## 一、需求背景

**目标用户**：使用资产升级服务清单服务名下客户的客户经理 / 投顾，与现有用户一致。  
**要解决的问题**：投顾在资产升级沟通思路第四步介绍资产配置时，需要按与客户的实际沟通选择匹配的大 C 方案。当前升级清单没有该五档方案的展示与随服务素材发送能力。完成后，投顾可在三个资产等级各自的第四步中查看五档方案占位、预览、选择，并将所选方案与现有对客服务内容一同触达。  
**竞品差异 / 品类惯例**：不适用。本次沿用本产品资产降级清单已有的客户级素材选择和群发交互，不做外部调研。  
**AI 能力边界**：不涉及 AI 生成或自动判断。系统不按客户 KYC、风险等级或画像自动推荐/勾选五档方案；档位由投顾结合实际沟通判断。

## 二、逻辑补齐摘要

### 2.1 主成功路径

投顾进入任一资产等级客户的沟通思路，展开第四步 → 打开大 C 方案素材选择 → 预览并勾选一个或多个方案 → 确认保存到当前客户 → 在服务话术上方核对所选方案 → 通过单客户触达或企微群发将方案作为素材发送。

### 2.2 关键分支

- 三个资产等级（300–500万、500–1000万、1000万以上）的第四步均展示同一组固定五档方案，不因资产等级隐藏方案档位；第四步正文仍分别沿用当前各等级完整原文。
- 投顾可多选五档中的任意组合；系统不自动匹配。首次选择默认全不选；再次打开读取当前客户上次确认的选择。
- 千人一面按现有资产等级、跃迁路径、现有沟通素材组合以及新增大 C 方案组合拆组；同组只发送相同素材组合。千人千面保留客户各自素材组合，并允许在群发确认中按客户调整。
- 未选择大 C 方案时，保留现有素材及群发口径，不额外附加大 C 素材；已选的现有沟通素材行为不变。

### 2.3 状态与异常

- 五档正式内容尚未提供，当前均使用明确标注的 PNG 占位进行列表和预览展示；不得生成或补写方案正文。每档支持独立下载；点击“预览长图”单独打开预览弹窗，不在列表卡片下方展开。企微群发弹窗不提供下载入口。
- 预览暂不可用时显示占位/不可预览提示，不阻塞选择其他档位。
- 取消或关闭未确认的选择窗口时，不保存本次草稿；确认后保存当前客户选择。切换客户后显示对应客户已确认选择。
- 素材确认后未能写入当前客户状态时，保留窗口和勾选草稿，允许重试或取消。
- 大 C 方案不拼入可编辑话术、不纳入一键复制；仍以独立素材形式发送。合规审核、服务完成、现有发送防重及发送结果回写规则保持不变。

### 2.4 跨页影响

- 入口页：资产升级服务清单客户详情中的沟通思路、服务话术和企微群发确认。
- 输出物：升级清单页面 PRD、原型、业务评审包、研发交付包。
- 降级清单仅作为既有交互参考，本次不修改降级清单及其交付包。

### 2.5 仍未决项

- 五档方案的真实 PNG 文件和正式内容尚未提供，不阻塞本期占位交互设计；后续提供正式图片时替换占位资源，不改变本次约定的五档名称、顺序和选择流程。

## 五、验收标准

1. 300–500万、500–1000万、1000万以上三个等级的第四步均可打开相同顺序的五档大 C 方案素材入口；每档均支持独立预览长图和下载。
2. 五档均显示 PNG 占位和预览；可多选；首次未选，关闭/取消不保存；确认后按客户保存且再次打开仍显示该客户已选档位。
3. 已选档位摘要显示在该客户服务话术上方；素材与话术保持分离，不进入话术编辑文本或一键复制内容。
4. 千人一面按新增方案组合拆组，组内所选大 C 方案一致；千人千面允许每位客户保留并调整自己的方案组合。
5. 未选大 C 方案时，现有沟通素材及其发送行为不变；发送防重与触达结果仍按现行规则工作。
6. 资产降级清单和不在本次范围内列出的其他页面、业务规则未发生变化。

## 六、风险与依赖

- 正式 PNG 尚未交付，原型以可辨识的 PNG 占位预览实现；研发需在正式素材到位后替换图片资源，并保留五档名称、排序和素材 ID 的稳定映射。
- 企微群发分组会因大 C 方案组合不同而增加组数；页面需清晰呈现拆组原因与每组发送素材，避免投顾误以为客户收到相同方案。
