本次交接范围

以下业务约束已写入 Spec 与主 PRD，供技术评审和测试设计使用。

核心串联

  • GWork 输入“账户诊断”触发串联 Skill
  • 资金账号在浏览器录入，不进入 GWork 或 Skill
  • 复用投前服务清单的录入与首次关系校验
  • 十部直接调用四部获取诊断结果

权限边界

  • 首次关系校验失败或异常时，不获取诊断结果
  • 结果页打开前由四部再次校验基础服务关系
  • 任一校验失败均不得打开结果页
  • 诊断不可用或打开失败时，重新发起完整流程

材料范围说明

本期不新增或改造页面原型：资金账号录入页复用理财产品投前服务清单既有页面，账户诊断结果页由四部提供。本包不包含页面 PRD、交互原型、接口字段、调用协议、凭证规则或技术架构设计。
