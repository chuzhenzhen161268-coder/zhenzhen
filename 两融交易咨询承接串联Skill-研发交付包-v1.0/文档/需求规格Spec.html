两融交易咨询承接串联 Skill

首期范围：GWork 单客户咨询承接　｜　平台：PC Web / GWork 对话串联　｜　版本：v1.0

一、需求背景

客户信用账户交易咨询需要在不输入资金账号明文的前提下，先查询佣金宝两融交易信息；命中时直接拿到错误内容，未命中时通过客户点击“？”或上传截图补充诊断信息。

二、已确认范围

  • 首期单客户承接，不做批量查询或左侧客户列表。
  • 不做咨询来源选择；GWork 发起咨询后自动弹出内部资金账号输入页面，所有咨询统一从账号查询开始。
  • 资金账号仅在内部页面录入，账号明文不进入 GWork。
  • 内部页面生成的任务码 taskid 即加密资金账号，二者是同一受保护标识，不是两个字段或两种凭据；沿用既有公共能力：10 分钟有效、一次性使用，本期不重复研发、不新增流程节点。
  • 查询命中约 5% 时，接口直接返回错误内容并进入服务清单，不调用两融试算原子 Skill。
  • 查询未命中约 95% 时，员工可引导客户点击佣金宝“？”重新查询，或上传交易截图。
  • 截图候选字段及准确性返回后判断完整性；不完整时通过任务码 taskid（即加密资金账号）补充或人工补录，完整后调用一部两融试算原子 Skill。
  • 截图不落库；OCR 类型、字段完整性、taskid 可补充信息范围和人工补录细节待技术确认。
  • 原子 Skill 按业务话术原文输出五段内容；个股诊断由串联 Skill 单独调用，服务清单只提供入口和复制链接。

三、端到端主流程

两融交易咨询承接主流程 · 首期单客户咨询 · 统一账号查询入口

四、服务清单职责

  • 展示上游返回的客户基础信息、信用账户总资产/净资产/总负债、待处理任务、逐笔错误/诊断明细和个股诊断入口。
  • 多次错误或多张截图按当前明细交互展示，按操作时间倒序，最新记录置顶。
  • 未得出诊断时展示“暂未识别原因，请通过人工渠道核实”，仍可完成服务。
  • 固定展示服务记录输入框和完成服务按钮，静态原型不模拟 GWork 交互。

五、异常与安全边界

  • 账号校验失败、任务码过期或已消费由既有专用页面处理，不进入服务清单。
  • 截图字段不完整由串联流程通过任务码 taskid（即加密资金账号）补充或人工补录；截图不保存。
  • 两融试算或个股诊断不可用不阻断服务记录和完成服务。
  • 资金账号明文不得进入 GWork。

六、待技术确认

OCR 支持截图类型、识别字段、字段完整性校验、任务码 taskid（即加密资金账号）可补充信息范围、人工补录字段清单、调用超时与重试策略仍需技术确认；这些事项不改变已确认主流程。
