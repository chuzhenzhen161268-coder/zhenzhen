# 两融交易咨询承接串联 Skill — 需求规格（Spec）

**产品名称**：两融交易咨询承接串联 Skill  
**模式**：新需求；首期承接 GWork 单客户两融交易咨询  
**平台类型**：PC Web / GWork 对话串联  
**版本**：v1.0  
**日期**：2026-11-16

## 一、需求背景

客户使用信用账户交易时，会在提交委托前因可买/可卖数量或试算结果产生疑问，也可能在提交委托后收到错误信息。员工需要在 GWork 中承接当前单个客户的咨询，通过资金账号查询佣金宝两融交易信息；查询命中时直接取得接口返回的错误内容，未命中时通过客户点击“？”重新查询或上传交易截图继续诊断。

**目标用户**：GWork 客户经理或投顾。  
**核心目标**：不在 GWork 对话框中输入资金账号的前提下，串联账号校验、佣金宝交易信息查询、未命中后的补充路径、两融试算、个股诊断和服务完成。  
**AI 能力边界**：截图识别只提取当次截图中的候选字段和识别准确性，字段必须校验完整；不完整时使用任务码 `taskid`（即加密资金账号）获取补充信息或提醒员工手动补录。`taskid` 与加密资金账号是同一受保护标识，不是两个凭据。原子 Skill 按已整理的错误场景规则输出，不推测缺失的账户、交易或风险数据。截图不落库。

## 二、已确认需求

- 首期只做单客户咨询承接，不提供批量客户查询，也不采用左侧客户列表。
- 员工在 GWork 对话框发起“两融交易咨询”后，GWork 自动弹出国金内部研发的资金账号输入页面；员工仅在该内部页面录入账号，账号明文不进入 GWork 对话框。
- 内部页面完成账号录入后生成受保护标识任务码 `taskid`，即加密资金账号；后续文档中的“任务码”和“加密资金账号”均指同一个 `taskid`，不得作为两个字段或两种凭据混用。
- 账号校验及交易信息查询沿用既有“理财产品投钱”场景的任务码流程：`taskid` 有效期 10 分钟、一次性使用。此规则复用既有公共页面/能力，不在本期重复研发，也不额外增加流程节点。
- 根据资金账号查询佣金宝两融交易错误信息：约 5% 命中时，由接口直接返回错误内容并进入当前客户服务清单，不调用两融试算原子 Skill；约 95% 未命中时，GWork 反馈未获取到交易信息并提供后续操作选择。
- 未命中后的操作：员工可引导客户在佣金宝点击“？”上报交易信息，之后重新弹出账号输入页并再次查询；或引导员工上传客户交易页面截图。
- 截图只用于当次识别，不落库。GWork 识别截图候选字段并返回识别准确性，之后判断字段是否完整。字段完整时调用一部两融试算原子 Skill；字段不完整时通过同一账号保护链路中的 `taskid`（加密资金账号）获取补充信息，或提醒员工手动补录，补录/补充后重新校验完整性。不得另造一个与 `taskid` 并列的“加密资金账号”参数。
- 截图支持类型、识别字段、字段完整性判定、`taskid` 可获取的补充信息范围和人工补录字段细节待技术确认。
- 一部两融试算原子 Skill 仅在截图路径字段完整后调用，输出五段标准内容：原因定位、数据说明、解决路径、风险提示、服务建议。具体规则由两融与投顾线老师按错误场景整理提供。
- 原子 Skill 按业务提供的标准话术原文返回，不做模型自行精简或综合改写；数据说明中的账户数值、委托数量等变量由接口自动填充，缺失时明确标记不可用。
- 个股诊断由 GWork 串联 Skill 单独调用，服务清单提供诊断入口和复制入口链接，不在清单内总结诊断内容；5% 命中路径不重复调用两融试算原子 Skill。
- “两融交易咨询服务”采用纵向单列服务清单，直接展示客户基础信息、信用账户总资产/净资产/总负债、待处理任务、逐笔交易诊断及个股诊断入口，不采用左侧客户列表或诊断侧栏。
- 服务清单只接收并展示上游返回的数据，不展示任务码，不处理账号录入、任务码校验、截图上传或重新查询。
- 当前浏览器页面不能与 GWork 交互；服务清单不模拟客户视图跳转、返回 GWork 或对话框内流程操作。
- 同一咨询出现多次错误或多张截图时，沿用明细切换交互，按操作时间倒序展示，最新记录在最上方；选择记录后查看对应诊断方案。
- 未得出诊断结果仍允许完成服务。
- 完成服务和结果回流完全复用现有投顾线服务清单上报逻辑，不修改字段、状态或处理规则。

## 三、逻辑补齐摘要

### 主路径

员工在 GWork 发起两融交易咨询，系统自动弹出内部资金账号页面。员工录入账号后，既有公共能力生成任务码 `taskid`（即加密资金账号），并用于账号校验和交易信息查询。命中（约 5%）时接口直接返回错误内容并进入当前客户服务清单，不调用两融试算原子 Skill；未命中（约 95%）时员工选择引导客户点击“？”后重新查询，或上传截图。截图字段完整则调用两融试算原子 Skill；不完整则通过 `taskid`（加密资金账号）补充信息或人工补录，再次校验。结果返回后由串联 Skill 单独调用个股诊断，进入单客户服务清单。

### 关键分支

1. **账号查询命中（约 5%）**：接口直接返回错误信息，进入服务清单；不调用两融试算原子 Skill。
2. **账号查询未命中（约 95%）**：GWork 提示未获取到交易信息，员工可选择引导客户点击“？”并重新弹出内部账号页查询，或上传客户交易截图。
3. **截图字段完整**：员工上传截图后，GWork 返回识别候选字段与准确性；字段完整则调用一部两融试算原子 Skill。
4. **截图字段不完整**：使用任务码 `taskid`（即加密资金账号）获取补充信息，或由 GWork 提示员工手动补录；补充后重新校验字段完整性，完整后调用原子 Skill。两种称呼指同一标识，不并列传参。
5. **任务码安全规则**：沿用既有公共功能，10 分钟有效、一次性使用；过期或消费后不可复用。该规则由既有账号/任务码页面承接，不新增流程节点或二次研发。
6. **无诊断结果**：展示可用信息，允许完成服务，回流行为不变。
7. **服务清单职责**：只展示上游已传入的客户、任务、交易明细、诊断与个股诊断入口；不反向发起账号、任务码、截图或 GWork 对话操作。

### 异常和安全边界

- 账号校验失败或服务关系校验不通过：不展示客户信息和交易明细。
- 任务码过期或已消费：按既有公共页面规则提示，不复用旧任务码；相关流程不在服务清单展示。
- 截图无法识别或字段不全：由员工确认、通过 `taskid`（即加密资金账号）补充或人工补录；截图不持久化。
- 两融试算失败：保留已取得的客户和交易上下文，提示暂不可用；允许按现有投顾线逻辑完成服务。
- 个股诊断失败：不阻断两融试算/错误信息和服务完成。

## 五、不在首期范围

- 咨询来源选择及佣金宝 APP / 其他交易 APP 分流。
- 批量客户查询、左侧客户列表、自动任务、消息提醒或定时推送。
- 重复研发既有任务码页面/公共能力，或在流程图中为任务码安全规则新增独立节点。
- 截图落库、截图历史检索、长期保存或再次使用。
- 修改两融试算原子 Skill 已整理的诊断规则。
- 修改投顾线完成服务上报逻辑或新增回流字段/状态。
- 在 GWork 对话中输入或透传资金账号明文。

## 六、验收标准

1. GWork 发起两融交易咨询后自动弹出内部资金账号输入页面，不出现佣金宝/其他交易 APP 来源选择。
2. 账号校验和任务码安全规则复用既有公共功能：任务码 `taskid`（即加密资金账号）有效期 10 分钟且一次性使用，不在服务清单展示或二次研发。
3. 查询命中（约 5%）时由接口直接返回错误内容并进入当前客户服务清单，不调用两融试算原子 Skill。
4. 查询未命中（约 95%）后可选择引导客户点击“？”重新查询，或上传截图；截图字段不完整时可通过任务码 `taskid`（即加密资金账号）补充信息或人工补录，并重新校验。
5. 截图字段完整后调用一部两融试算原子 Skill；五段内容按业务话术原文展示，数据变量由接口自动填充。
6. 服务清单无左侧客户列表或诊断侧栏，按纵向单列展示客户信息、三项信用账户资产、待处理任务、逐笔诊断与个股诊断入口；页面不展示资金账号录入、任务码、过期状态或重新查询。
7. 同一次咨询多条记录按时间倒序显示；切换记录时对应诊断内容同步切换。
8. 个股诊断由串联 Skill 单独调用，清单提供入口和复制链接，不展示诊断总结。
9. 无诊断结果仍可完成服务，服务上报行为与投顾线现有逻辑一致。

## 七、风险与技术依赖

- OCR 支持的截图类型、识别字段、完整性校验、`taskid` 可补充信息范围和人工补录字段待技术确认；不改变已确认主流程。
- 依赖既有内部账号输入/任务码公共页面（理财产品投钱场景已有，不做二次研发）；该页面生成的 `taskid` 即加密资金账号，并供截图字段补充使用。另依赖服务关系校验、佣金宝交易信息查询接口、两融试算原子 Skill 和个股诊断能力。
- 依赖业务提供按错误场景整理的五段标准内容及所需数据口径。
- 完成服务回流依赖现有投顾线服务清单能力，本需求不改造其行为。
