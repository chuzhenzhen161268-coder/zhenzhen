# 产品需求文档：高净值客户资产降级服务清单

> 版本：v1.0（未上线前不升版本）  
> 适用端：PC Web

## 1. 项目概览

高净值客户因市场波动、账户亏损或资金转出发生资产档位下降后，客户经理需要及时识别客户、理解账户变化并完成针对性的回访和服务承接。本场景为与资产升级服务清单并列的独立服务清单，复用 AI+服务清单的列表—详情、基础信息、待处理任务、电话外呼、企微群发和完成服务能力。

目标是在自动任务或 WorkBuddy 查询后，向员工提供降级路径、客户画像、资产降级原因判断、完整沟通思路、摘要式服务话术和服务结果回写。

## 2. 核心规则

| 功能 | 规则 |
| --- | --- |
| 圈客入口 | 支持每日自动任务、WorkBuddy 自由圈客和快捷生成。自动任务及快捷生成均识别近 20 日日均净资产较昨日下降的客户；自由圈客按员工明确条件执行。 |
| 降级路径 | 覆盖 1000万以上→500–1000万、500–1000万→300–500万、300–500万→300万以下。一次跨越两个及以上档位也纳入清单，按降级后的当前资产层级对应路径服务。 |
| 原因判断 | 业务已确认：账户亏损额取负盈亏绝对值、盈利按0；净资金转出按正向转出额、净流入按0。每周期两项数据均有效时，达到对方1.5倍（含）投对应主导票；三周期中任一方向至少2票归该主导原因；有效周期≥2但无方向取得2票归混合原因；有效周期<2归原因不明。 |
| 服务优先级 | 不做近 90 天剔除；按近 90 天“未联系优先 → 降级路径 → 当前资产”排序。点击完成服务、企微发送客户成功均视为已联系。 |
| 沟通思路 | 按降级路径完整展示业务提供的【亏损场景】【资金转出场景】【主动资产配置引导】和应答示例，仅供投顾参考，不进入对客发送内容。 |
| 服务话术 | 以降级路径 × 原因判断对应的业务示例为参照，默认引用 1 个、最多 2 个有效画像切入点生成摘要式话术；有效切入点须相关、完整可信且可转为中性表述；无有效切入点时用通用回访话术。详细规则见页面 PRD。 |
| 企微群发 | 支持千人一面和千人千面。千人一面按相同降级路径、相同原因判断和相同素材组合分组；以企微“发送客户成功”回执写入防重标记。 |
| 数据缺失 | 画像显示“--”或数据不可用，不得编造；关键盈亏/资金数据缺失时允许使用通用回访话术触达。 |

## 3. 页面与流程

页面采用左侧客户列表、右侧客户详情布局。左侧支持姓名/资金账号、资产等级和资产降级原因判断的组合筛选；右侧展示基础信息、ISMP 待处理任务、降级画像、沟通思路、服务话术和服务操作。

## 4. 数据与依赖

- 资产数据：近 20 日日均净资产及昨日对比，用于识别降级路径。
- AI+助手：账户盈亏、行业持仓结构及相关画像数据。
- 资金数据：近 1 月、近 3 月、近半年净资金转出。
- ISMP / 服务记录：待处理任务、最近有效沟通日期、渠道与近半年有效服务次数。
- 企微：发送客户成功回执，用于防重和已联系排序。

## 5. 待业务确认

1. 三条路径的沟通思路原文和展示方式；
2. 服务话术生成参照、有效画像切入点和禁用表达；
3. 近半年有效服务次数的统计窗口、计入事件和数据来源。
