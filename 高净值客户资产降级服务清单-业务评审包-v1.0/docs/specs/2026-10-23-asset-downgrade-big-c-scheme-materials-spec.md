# 资产降级服务清单：五档大 C 方案素材 Spec

## 1. 需求背景

在高净值客户资产降级服务清单的沟通思路中，主动资产配置引导需要支持五档大 C 方案素材。五档方案对应的具体文档尚未提供，本期使用 PNG 占位；方案档位由投顾结合与客户的实际沟通判断，不由系统 KYC 自动匹配。

本次为既有降级服务清单的单页迭代，沿用 AI+服务清单视觉、话术编辑、触达和防重规则，不改变资产降级原因判断算法及既有话术生成规则。

## 2. 逻辑补齐摘要

- 主路径：员工进入客户详情 → 展开“主动资产配置引导” → 点击“选择大 C 方案素材” → 在侧面板多选五档方案；点击“预览长图”单独打开长图预览弹窗（不在卡片下方展开），支持滚动查看与下载 → 确认 → 将已选素材与服务话术一起用于触达。
- 关键分支：首次打开全部不勾选；可多选；无素材时仍可只发送服务话术；千人一面按降级路径、原因判断和素材组合分组；千人千面按客户独立素材组合发送。
- 状态/异常：预览失败不阻塞其他选择；确认失败保留勾选状态；已发送素材沿用现有触达记录和企微成功回执防重。
- 跨页影响：降级清单原型、降级页面 PRD、业务评审包、研发交付包；升级服务清单不改。
- 仍未决：五档 PNG 正式内容和最终文件由业务后续提供，本期明确为占位素材。

## 4. 功能变化

### 4.1 素材入口与面板

在每条客户降级路径的“主动资产配置引导”沟通思路中增加 `选择大 C 方案素材` 入口。入口打开侧面素材面板，不改变沟通思路正文布局。

面板固定展示以下五档，顺序不可变：

1. 低波动方案
2. 中低波动方案
3. 中波动方案
4. 中高波动方案
5. 高波动方案

每档展示 PNG 缩略图、方案名称、预览操作和复选框。方案内容暂使用占位 PNG，不由系统生成或补写正文。

### 4.2 选择、预览与确认

- 首次打开全部不勾选。
- 支持多选；投顾根据实际沟通判断选择一个或多个档位，不执行 KYC 自动匹配。
- 点击“预览长图”单独打开当前 PNG 的长图预览弹窗，不在素材卡片下方展开；预览弹窗支持滚动查看、关闭和下载 PNG。预览失败显示不可预览状态，但不影响其他素材选择。
- 每档卡片提供独立下载操作；本期未提供正式 PNG 时，预览和下载使用清楚标注的占位 PNG；正式方案图片接入后，预览与下载均指向真实图片资源。
- 点击确认素材后关闭面板，入口显示“已选 N 份”，并在服务话术上方展示已选素材摘要。
- 重新打开面板保留当前客户最近一次确认的选择；未确认关闭面板不保存变更。
- 未选择素材时，服务话术仍可独立复制、单聊或群发。

### 4.3 触达与分组

- 单客户触达：沿用 AI+服务清单交互，发送已选素材和当前服务话术；支持只发送话术。
- 千人一面：按 `降级路径 + 资产降级原因 + 素材组合` 分组，同组发送同一份服务话术和同一组素材；不混入单个客户画像。
- 千人千面：每个客户使用其独立服务话术和素材组合，支持在发送前逐客户调整。
- 企微发送成功以企微成功回执写入防重记录；沿用当前场景 90 天联系口径及重复发送拦截。

### 4.4 数据记录

每次确认或发送记录：客户 ID、降级路径、原因判断、素材 ID 列表、素材版本/占位标识、触达渠道、发送结果和时间。未发送的勾选不写入有效触达记录。

## 5. 不在本次范围内

- 不自动读取或推断客户 KYC 并选择方案。
- 不生成、改写或审核五档方案正文。
- 不改变资产降级原因判断、服务话术生成、合规审核和完成服务规则。
- 不新增升级服务清单页面或素材模块。

## 6. 验收标准

- 客户详情的主动资产配置引导步骤可打开素材面板。
- 五档方案名称、顺序和 PNG 占位均正确展示。
- 首次打开全部未选；可多选、独立打开长图预览、下载 PNG、确认和取消；预览不在素材卡片下方展开。
- 取消不保存本次变更，确认后再次打开能看到上次确认选择。
- 未选素材时仍可正常发送服务话术。
- 千人一面按路径、原因和素材组合正确拆组；千人千面按客户保留独立素材组合。
- 发送成功回执、防重、触达记录与现有降级清单规则一致。
